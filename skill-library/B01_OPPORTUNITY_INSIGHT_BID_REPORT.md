# B01 机会洞察与商业论证：首轮 Skill 初筛

## 本轮结论

已从 B01 的候选池中选出 5 个代表 Skill，覆盖一条最小、不断档的业务链：从消费者说了什么，到购买前在找什么，再到哪些需求缺口值得进入经营比较，以及如何验证长期价值。

| 站位 | 候选 | 初筛结论 | 直接交付 |
| --- | --- | --- | --- |
| D01 | `p2s-voc-aspect-sentiment-extraction` | 可开展样本试跑 | 可追溯的评论方面问题证据 |
| D02 | `p2s-search-voc-signal-loop` | 可开展样本试跑 | 购买前的高频未满足需求线索 |
| D03 | `p2s-voc-new-product-gap-scoring` | 条件入围，先补证 | 带公式与覆盖说明的机会假设排序 |
| C01 | `p2s-sc-whatif-scenario-analysis-engine` | 条件入围，先补证 | 经营选项、不确定性和验证建议 |
| V01 | `p2s-long-term-holdout-group-design` | 条件入围，先补证 | 长期价值验证设计 |

这不是一轮岗位任命，也没有产生真实新品结论。它只确认：这五项材料值得进入同一条受控的样本试跑链路。

## 为什么是这五项

三项消费者需求洞察候选分别处理不同证据：D01 把已购买用户的评论拆成可回看原文的具体问题，D02 用购买前搜索语言补足评论的滞后与选择偏差，D03 把竞争问题整理成待验证的机会假设。它们不会被合并为一个“VOC 大模型”，因为输入来源、输出粒度和失败方式不同。

两项商业论证候选也不重叠：C01 比较同一经营问题下的多个选项，要求说清经济口径、识别假设和不确定性；V01 检验短期有效是否能持续，避免把新鲜感或短期波动当成长期价值。

## 首轮试跑的共同任务

用一个已确定、已脱敏且可合法使用的品类样本包做受控试跑。每项 Skill 只交付自己的最小产物，并在同一经营事项下顺序交接：

1. D01 输出评论中的方面级支持、反证和未知。
2. D02 输出购买前需求线索，并与 D01 保留一致和冲突之处。
3. D03 只把证据整理成机会假设排序，不能替代成本、供给、认证或投入判断。
4. C01 仅在数据和识别条件满足时，对可选路径作统一口径的价值、毛利和不确定性比较。
5. V01 只形成长期验证设计；是否分配真实用户、是否开展业务动作，仍由已有职责和授权决定。

## 进入下一轮前必须补齐的证据

| 候选 | 必须补齐 |
| --- | --- |
| D01 | 品类方面表、多语言标签一致性、评论样本代表性 |
| D02 | 搜索词来源与时间窗覆盖、意图识别质量、与其他证据的交叉验证 |
| D03 | 评分参数的可解释性与稳定性、市场规模口径、需求侧与可行性判断的边界 |
| C01 | 弹性标定、可比历史数据、因果识别假设和区间估计 |
| V01 | 用户数据、分桶能力、权益告知与合规、样本量和业务损失的可接受性 |

## 与三宝蓝图的关系

- **C-018 消费者需求洞察**：D01、D02、D03 的产物应成为带来源、范围、支持、反证和未知的需求证据与问题地图，而不是直接写成产品规格或投资建议。
- **C-021 商业论证**：C01、V01 的产物应成为可比较的经营选项与验证建议，说明价值假设、经济条件、投入风险、学习价值和下一步验证，不替代有权责任方的经营取舍。
- **能力竞聘边界**：当前只比较原子 Skill 在一个最小能力站位的交付质量；岗位 Bundle、Preset、数字员工和真实业务动作均不在本轮范围内。

## 资料质量说明

五项候选的本地原始 Skill 都能读到输入、输出和边界。前三项的卡载论文标注与主题不符，不能把论文编号当成背书；C01 的论文线索仍需对一手来源及重复引用复核；V01 没有提供可采信的论文出处。首轮优先用受控样本和可追溯输出检验它们，不以卡片中的 ROI 示例作为经营事实。
