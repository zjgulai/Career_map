## ② 核心算法逻辑

买家在评论中隐含大量问答对：'我家宝宝6个月能用吗？用了3个月效果很好'→Q:6个月宝宝适用? A:适用。从海量评论中自动抽取这类隐含Q&A，构建产品FAQ，提升Listing问答区质量和买家转化。

```python
import re

def extract_qa_pairs(reviews: list) -> list:
    qa_patterns = [
        (r"(\d+[\s个月岁].*?(?:能|可以|适合|好不好).*?)[？?。].*?(好|不好|适合|推荐|不推荐)", "age_suitability"),
        (r"(几个月|多大|年龄).*?(?:可以|能|适用).*?(好|可以|适合|不建议)", "age_query"),
    ]
    results = []
    for review in reviews:
        text = review.get("text", "")
        for pattern, q_type in qa_patterns:
            matches = re.findall(pattern, text, re.IGNORECASE)
            if matches:
                results.append({"type": q_type, "source": text[:80], "match": matches[0]})
    return results

sample_reviews = [
    {"text": "宝宝6个月开始用，吃了3个月效果很好，身高增长明显"},
    {"text": "几个月的宝宝可以用？我家4个月宝宝适合吗？用了感觉不错"},
    {"text": "味道很好，宝宝很爱吃，推荐"},
]
qas = extract_qa_pairs(sample_reviews)
print(f"抽取到 {len(qas)} 个Q&A对: {qas[:2]}")
assert len(qas) >= 1
print("[✓] Review QA Extraction 测试通过")
```

## 输入 / 输出契约

**输入**：产品评论语料（卡页示例 1000 条以上）与已有问答区 Q&A 数据；粒度为单条评论文本。

**输出**：Top50 问答对、高频问题频次排序与建议补充的 FAQ 清单；供 listing 运营与客服团队直接落地使用。

## 执行步骤

1. 收集目标产品的评论语料与现有问答区内容
2. 用问答模式规则从评论中匹配隐含问答对
3. 按出现频次对问题排序，取高频 Top 问题
4. 汇总为建议补充的 FAQ 清单
5. 复核内容准确性后发布到问答区

## 边界与不做

- 数据不满足：评论量太少或与产品无关时抽不出有效问答对，先积累足够评论。
- 何时不用：评论情感与根因分析用「差评根因分析」，方面情感批量提取用「评论结构化抽取」。
- 能力边界：只从既有评论中抽取问答，不生成评论中不存在的信息，也不替代客服的正式答复口径。
- 安全边界：FAQ 必须基于真实评论且经人工复核，不得捏造或放大功效表述。
