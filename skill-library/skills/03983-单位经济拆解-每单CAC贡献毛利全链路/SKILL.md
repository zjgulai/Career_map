# Unit Economics Decomposition — 单位经济拆解（每单CAC/LTV/贡献毛利全链路）

## ① 解决的问题

财务团队面临"不知道每单真实贡献毛利导致高频亏损SKU持续运营"——单位经济全链路拆解将亏损SKU识别准确率提升90%，年化优化SKU组合提升整体毛利30-60万元

## ② 核心算法逻辑

单位经济模型将每笔订单的所有成本和收益量化到单位级别：商品成本+FBA费用+广告分摊+退货成本+客服成本 vs 售价+LTV预期。母婴高频复购场景下，首单亏损但LTV为正的SKU值得持续投入。关键指标：CAC/LTV比（<3=健康）。

## 输入 / 输出契约

**输入**：历史订单与费用数据（售价、商品成本、FBA 费、广告分摊、退货与客服成本）及用户复购与 LTV 口径；粒度：订单级或 SKU 级，按周期滚动更新。

## 执行步骤

1. 汇总单位级收入与成本项并确认分摊口径
2. 按订单或 SKU 归集，计算每单贡献毛利
3. 计算 CAC 与 LTV 并求比值
4. 标记首单亏损但 LTV 为正与持续亏损两类 SKU
5. 输出 SKU 投入取舍与优化建议

## 边界与不做

- 数据不满足时不用：没有订单级成本分摊口径（广告、退货、客服如何摊到单）时，单位经济结论失真。
- 能力边界：只做单位经济核算与识别，不自动调价、不停投广告；LTV 口径需与财务统一后才可用于对外报告。
