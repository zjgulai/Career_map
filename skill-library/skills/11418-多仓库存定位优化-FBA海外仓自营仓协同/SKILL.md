# Inventory Positioning Multi-DC — 多仓库存定位优化（FBA+海外仓+自营仓协同）

## ① 解决的问题

供应链团队面临"FBA断货和海外仓积压并存说明多仓库存定位失衡"——随机库存定位模型优化后断货率降低30%仓储成本降低20%，年化节省25-45万元

## ② 核心算法逻辑

母婴卖家同时运营FBA/海外仓/自营仓，库存定位优化问题：在总预算约束下最小化断货成本+持仓成本。随机库存定位模型（Stochastic Inventory Location），按断货成本/持有成本比率动态分配各仓库存。

## 输入 / 输出契约

**输入**：SKU×仓粒度的历史与实时数据：各仓当前库存量、在途量、历史销量与需求波动，以及断货（缺货）成本、单位持有（仓储）成本和可投入的库存总预算约束。

**输出**：量化决策支持报告与可操作建议：每个 SKU 在 FBA／海外仓／自营仓的目标库存分配量、按断货成本与持有成本比率给出的优先分配顺序、断货率与仓储成本的改善幅度预估，以及需调拨或清货的清单；供供应链团队做仓位与预算分配决策。

## 执行步骤

1. 汇总 FBA、海外仓、自营仓各 SKU 的库存量、在途量与近期销量
2. 逐 SKU 计算断货成本与持有成本的比率，判断货是卡在断货端还是积压端
3. 在总预算约束下求解各仓的目标库存分配量
4. 把分配结果与现状的差额排成调拨、清货的优先顺序
5. 输出量化决策支持报告，标注成本与断货率的测算口径与模型更新周期

## 边界与不做

- 数据不满足时不用：缺各仓库存、在途量或成本参数的 SKU 无法做定位分配。
- 只给分配与调拨建议，不直接执行调拨、清货或在售状态变更。
- 卡页 ROI（断货率降低 30%、仓储成本降低 20%、年化节省 25-45 万元）为估算口径，落地前须用本店实际数据重算，并定期更新模型以适配业务变化。
