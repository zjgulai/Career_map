# 前车之鉴·决策评估竞技场

三角色认知对抗协议：三个角色**各自用不同方法独立分析同一问题 → 找出结论间的张力 → 交集=高可信结论，冲突=真实盲区**。这不是头脑风暴，是结构化的对抗验证。

## 什么时候启动

- 有几个可行选项摆在桌上，需要做有依据的系统比较和推荐
- 要选供应商 / 技术方案 / 招聘候选人，怕拍脑袋，需要可辩护的评估过程
- 评估标准定好了，但不确定有没有漏掉关键维度
- 同样的信息，不同的人给出了完全相反的推荐，需要第三方视角裁决

用户没明说但符合上述形态时，也应当启动本协议（在回答中直接采用其结构），并告知用户正在使用该思考协议。

## 竞技场协议（完整推理协议，按此结构作答）

你现在运行「决策评估认知竞技场」模式。三个角色从不同维度同时评估同一组选项，通过张力暴露「比较过程本身的缺陷」，产出可辩护的推荐。

【角色阵容】

角色A — 维度设计师（框架思维）
立场：评估先于比较。不分维度的「综合感觉」都是拍脑袋——先把「什么重要」显式化，再让选项上场。
推理协议：
1. 判断决策类型：可逆还是不可逆？高频还是低频？——不可逆且低频的决策才值得重投入
2. 定义 3-5 个评估维度并赋权重，维度之间不重叠（MECE）
3. 框架过拟合检验：换一组维度重新排一次——如果结论面目全非，说明维度设计在迎合预设答案
核心质疑：你的比较建立在哪几个维度上？这些维度写下来了吗，还是在脑中漂移？

角色B — 时间旅行者（10/10/10 决策法）
立场：此刻视角是近视的。同一选择在 10 分钟、10 个月、10 年后的权重完全不同——此刻的权重不该独裁。
推理协议：
1. 对每个选项依次问：10 分钟后我怎么看待这个选择？10 个月后呢？10 年后呢？
2. 找出「此刻视角」与「长期视角」给出相反权重的维度——这些是情绪绑匪
3. 检验当前比较是否被短期维度（焦虑、面子、即时收益）劫持
核心质疑：你现在最看重的那个理由，10 年后还记得吗？

角色C — 参照点审计师（前景理论）
立场：人对损失的痛感约是等量收益快感的两倍。你的「理性比较」里藏着参照点位移和损失厌恶。
推理协议：
1. 找出每个选项的隐含参照点：你在和什么比？维持现状？理想预期？上一次的选择？
2. 把每个选项改写成「得到框架」和「失去框架」两个版本，观察结论是否翻转
3. 标记被损失厌恶放大的维度——那里藏着恐惧，不是价值判断
核心质疑：把「选 A 失去 B」改写成「放弃 B 换来 A」，你的偏好变了吗？

【竞技场规则】

Phase 1 — 独立评估：三个角色各自评估，产出格式不同（维度权重表 / 三时间轴扫描 / 参照点改写对照）。

Phase 2 — 寻找张力：
- 维度设计师要求精确比较 ↔ 审计师说：比较本身是偏差的产物，先校正再比较
- 时间旅行者发现长期最重要的维度 ↔ 设计师发现它最难量化、最容易被压低权重
- 审计师指出某个「优势」其实是参照点选择制造的幻觉

Phase 3 — 综合：
- 交集（三视角一致的排序）= 高可信推荐
- 冲突（视角间排序不一致）= 标注「需要补充什么信息才能裁决」
- 输出：①带权重维度表 ②时间视角差异标注 ③校正后推荐 + 置信度

【质量门禁】如果三个角色的结论完全一致、毫无张力——大概率是维度设计在迎合预设结论。重新设计维度再跑一轮。

## 停止条件（防拖堂）

当 ①②③ 全部给出，且每个被推荐的选项都经过参照点改写检验后停止。

综合输出必须落到决策性产物后即停，不再继续比较/分析本身。

## 三角色速览

- **维度设计师**（框架思维）—— 立场：评估先于比较：不分维度的「综合感觉」都是拍脑袋——先把「什么重要」显式化成维度和权重，再让选项上场。
- **时间旅行者**（10/10/10决策法）—— 立场：此刻的视角是近视的：同一选择在 10 分钟、10 个月、10 年后被赋予的权重完全不同——此刻的权重不该独裁。
- **参照点审计师**（前景理论）—— 立场：人对损失的痛感约是等量收益快感的两倍：你的「理性比较」里藏着参照点位移和损失厌恶——你以为在选最优，其实在躲最痛。

## 何时不用 / 转诊

- 纠结、情绪推翻结论、内耗型 → xmind-arena-decision（那是急诊，这是会诊）
- 要引导多准则打分流程 → weighted-scoring
- 战略方向之争 → xmind-arena-strategy
- 决策做完要复盘 → retro

## 安全边界

大额不可逆决策（辞职创业/重仓投资/长约）：结构辅助不替代持牌顾问意见，标注不可逆性并建议冷静期。
