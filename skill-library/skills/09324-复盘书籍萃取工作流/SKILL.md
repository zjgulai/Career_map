# SKILL: 复盘书籍萃取工作流

> **名称**：book-extraction-workflow
> **版本**：v1.0
> **创建日期**：2026-04-27
> **适用范围**：对「复盘」主题多本书籍进行系统性深度萃取

---

## 1. Skill 概述

本 Skill 提供一套完整的「三阶十步萃取工作流」，帮助你将多本同类主题书籍转化为：
- ✅ 经过逻辑检核的可信知识
- ✅ 可迁移的思维模型
- ✅ 可执行的工作模板
- ✅ 可检索的知识卡片
- ✅ 可训练的能力题库
- ✅ 可长期运行的个人操作系统

### 适用场景

- 你需要对 2 本以上同类主题书籍进行深度阅读和比较
- 你不满足于「做笔记」，希望「学以致用」
- 你希望将书籍知识沉淀为可长期调用的个人知识资产
- 你希望读书后形成可执行的行为改变，而非只停留在认知层面

### 不适用场景

- 你只需要快速了解一本书的大意（本工作流过重）
- 你读的是小说/散文等非工具类书籍（本工作流针对方法论/工具型书籍设计）
- 你没有时间投入深度萃取（单本书全流程约需 8–12 小时）

## 2. 快速开始

### 3 步启动

```
Step 1: 加载工作流
   → 在 Kimi CLI 中输入 /skill:book-extraction-workflow
   → 或向 AI 提供 prompt/三阶十步萃取总控.md 的内容

Step 2: 选择书籍
   → 从 book/ 目录中选择第一本要萃取的书
   → 推荐顺序：虚舟 → 邱昭良 → 郑强 → 沈磊

Step 3: 执行步骤1
   → 向 AI 提供本书的目录 + 前言/结语 + 各章首尾段
   → 调用「第一阶-单书深度萃取.md」中的「步骤1：结构真相体检」
```

## 4. 每个阶段的执行指令

### 阶段一：单书深度萃取

**执行方式**：
1. 打开 `prompt/第一阶-单书深度萃取.md`
2. 从「步骤1」开始，逐步骤向 AI 提供输入
3. 每完成一步，确认输出质量后再进入下一步
4. 步骤之间有过滤门和衔接条件，不得跳过

**关键检查点**：
- 步骤1 的「准入报告」决定后续投入深度
- 步骤3 和步骤4 不可合并（先模型、后转译）
- 步骤8 不可跳过（三句话价值判定）

### 阶段二：跨书对比整合

**执行方式**：
1. 确保四本书的步骤7（知识卡片）和步骤8（价值判定）全部完成
2. 打开 `prompt/第二阶-跨书对比整合.md`
3. 向 AI 提供四本书的全部知识卡片和价值判定书
4. 按「板块一→五」顺序执行

**关键检查点**：
- 必须引用卡片原文，不能凭记忆
- 冲突点必须有证据支撑
- 适用矩阵必须诚实标注「不适用」

### 阶段三：个人系统构建

**执行方式**：
1. 确保步骤9 全部完成
2. 打开 `prompt/第三阶-个人系统构建.md`
3. 向 AI 提供步骤9 的全部产出
4. 可选择性提供个人背景（角色/场景/工具/时间上限）
5. 按「板块一→四」顺序执行

**关键检查点**：
- 系统必须「可执行、可坚持、可复盘」
- 不要设计理想化系统，要设计你能坚持的系统
- 保留 Plan B 空间

## 10. 常见问题

**Q1：我必须严格按顺序执行全部10个步骤吗？**
A：第一阶的8个步骤内部有严格的过滤门和衔接条件，不建议跳过。但你可以根据步骤1的「准入报告」压缩不值得深入章节的投入。第二阶和第三阶必须在四本书全部完成后执行。

**Q2：我可以只萃取一本书吗？**
A：可以。只执行第一阶（步骤1–8）即可。但本工作流的最大价值在于多书对比后的整合与系统构建。

**Q3：每本书真的需要8–12小时吗？**
A：这是深度萃取的参考时间，包括你的阅读和思考时间。如果某本书步骤1后被大量搁置，实际时间会缩短。

**Q4：知识卡片必须存入Obsidian/Notion吗？**
A：不限定工具。你可以用任何支持Markdown的知识库工具，甚至纸质笔记本。关键是格式统一、可检索。

**Q5：如果我发现某本书质量很差怎么办？**
A：步骤1的「准入报告」就是为此设计的。如果一本书的 ✅ 内容极少，你可以果断放弃深入萃取，把时间留给更有价值的书。
