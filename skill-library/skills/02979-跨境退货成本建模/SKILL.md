## 输入 / 输出契约

**输入**：欧洲站历史退货记录与 SKU 级销售数据，以及退货物流成本口径（国际运费、海关费、检验费、销毁成本），粒度需到 SKU 与订单行。

**输出**：SKU 级退货率预测与退货调整后的真实毛利率，用于选品与定价参考，并据此判断高退货 SKU 是否继续备货。

## 执行步骤

1. 汇总退货场景下的全部成本项，含国际运费、海关费、检验费与销毁成本
2. 用历史退货数据训练 SKU 级退货率预测模型
3. 把退货成本摊回 SKU，算出退货调整后的真实毛利率
4. 输出高退货 SKU 清单作为备货与定价调整依据

## 边界与不做

- 退货量过小或历史退货记录缺失时无法拟合退货率，结论不可用
- 只做成本还原与毛利率修正，不做停售或定价决策，需与选品和定价流程联动
