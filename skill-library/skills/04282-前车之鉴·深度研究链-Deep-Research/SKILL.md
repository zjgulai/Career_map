# 前车之鉴·深度研究链（Deep Research）

> 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论。适用问题形态：复杂现象的根因研究 / 需要综合多方信息的分析 / 战略性问题研究 / 知识图谱构建。

## 何时用

- 问题涉及多个相互影响的变量
- 需要区分「已知」「未知」「不可知」三类信息
- 结论需要引用证据支撑，不能依赖直觉

本技能是**选型图纸 + 相位纪律模板**：用于①给新任务选定执行形态；②设计 subagent / workflow / goal 派工时套用相位结构（checkpoint 做验收门、stop_condition 做终止判据、loop_back 做回环路径）。

## 五链对照（先选对形态）

| 链 | 定位 |
|---|---|
| xmind-chain-react | Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务 |
| xmind-chain-tot | Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径 |
| xmind-chain-cot-critic | 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务 |
| xmind-chain-research | 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论 | **←本链**
| xmind-chain-per | 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行 |

## 本链 5 相位纪律

| 相位 | 输入 → 输出 | 检查点 | 停止/回环 | 关联模型 |
|---|---|---|---|---|
| 1. 问题精炼（Question Refinement） | 原始研究问题 → 精炼后的研究问题 + 研究边界 + 排除范围 | 将模糊研究问题精炼为可操作的研究问题。区分：1) 已知是什么 2) 真正想知道什么 3) 这是可以研究的吗（可操作性） | 停止：产出可供下一阶段使用的结果 — | 爱因斯坦式提问_5步重新定义 |
| 2. 假设生成（Hypothesis Generation） | 精炼后的研究问题 + 已知信息 → 假设清单：每个假设 = {假设内容, 核心前提, 如果成立会看到的证据, 如果不成立会看到的证据} | 基于已知信息，生成3-5个竞争性假设。每个假设必须：1) 可证伪 2) 与其他假设有根本区别 3) 有明确的证据模式（如果这个假设成立，会看到什么） | 停止：产出可供下一阶段使用的结果 — | 批判性思维工具包_3步拆解论 |
| 3. 证据搜集（Evidence Collection） | 假设清单 → 证据矩阵：行=假设，列=证据类别，格=支持/反对/中立 + 来源 | 针对每个假设，系统搜集支持/反对的证据。记录：1) 证据来源 2) 证据质量（直接/间接/传闻） 3) 证据支持哪个假设 | 停止：产出可供下一阶段使用的结果 — | 批判性思维工具包_3步拆解论 |
| 4. 假设检验（Hypothesis Testing） | 假设清单 + 证据矩阵 → 检验结论：{最支持的假设, 排除的假设, 需要更多证据的假设, 修正后的假设（如有）} | 用证据矩阵检验每个假设。判断：1) 证据充分支持哪个假设？2) 哪个假设被证伪？3) 是否需要修正假设？ | 停止：产出可供下一阶段使用的结果 — | 批判性思维工具包_3步拆解论 |
| 5. 综合与洞察（Synthesis & Insight） | 所有假设检验结论 → 研究报告：{核心发现（3条以内）, 反常识发现, 知识边界, 实践建议, 后续研究方向} | 将检验结论综合为系统性洞察。提炼：1) 核心发现 2) 与已有认知的矛盾点 3) 还需要验证的关键未知 4) 实践意义 | 停止：产出可供下一阶段使用的结果 — | 金字塔原理_理清逻辑_高效表 |

## 落地用法

1. **编排派工**：把上表转成 subagent/workflow 的执行步骤；每相位产出必须先过检查点再进下一相位；触发回环条件时显式回到目标相位，不要静默重试。
2. **运行时纪律**：正在执行的任务陷入停滞时，对照当前相位的 stop_condition 判断是「该停」还是「该回环」，避免无限循环。
3. **关联模型深化**：各相位关联模型的完整推理协议用 xmind-gateway 的查询配方读取（四层结构 system_prompt 可直接注入对应相位执行者）。

## 何时不用 / 转诊

- 纯推理无外部交互 → xmind-chain-cot-critic；要工具交互迭代 → xmind-chain-react
- 多方案并行探索 → xmind-chain-tot；系统性多源研究 → xmind-chain-research
- 多阶段项目管理 → xmind-chain-per；单步低风险任务直接做
