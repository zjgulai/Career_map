## 输入 / 输出契约

**输入**：各平台的预算档位与对应效果数据、构造 QUBO 目标函数所需的高维归因数据，以及总预算与各平台预算上下界；需要 QUBO 建模经验。

**输出**：跨平台预算的全局最优组合建议，含与按单渠道 ROAS 排序方案的对比，供投放决策层采用。

## 执行步骤

1. 汇总各平台预算档位与对应效果数据
2. 把跨平台预算分配编码为含总量与渠道边界约束的 QUBO 目标函数
3. 用量子退火求解器搜索全局最优组合
4. 与按单渠道 ROAS 排序的局部最优方案对比
5. 输出跨平台预算组合建议供决策层采用

## 边界与不做

- 何时不用：渠道数很少、梯度法已能得到稳定解时不必要；缺少高维归因数据时不应套用 QUBO 建模。
- 能力边界：只产出预算组合建议，不执行平台预算变更；原卡标注实施难度为五星，需要 QUBO 建模经验。
- 结果边界：全局解依赖目标函数编码口径，编码方式变化会显著改变分配结果，须在方案中写明编码假设。
