### Step E-1 · 数据获取

#### 通路 A · MCP + web_search 组合

**飙升词（需求新信号）**
```bash
accio-mcp-cli call data_advisor_industry_crowd_insight --json '{"crowdInsightQueryParam": {"industryId": "{{CATE_ID}}", "nd": "30d", "terminalType": "TOTAL"}}'
```
提取：`seKwRate`（飙升词 Top20）→ 反映近期买家需求的新兴方向

**关键词历史趋势（Jungle Scout）**
```bash
accio-mcp-cli call js_historical_search_volume --json '{"keyword": "{{CATEGORY_INPUT}}", "marketplace": "us"}'
```
识别：季节性峰值月份、近12个月搜索量趋势

**C端热销信号 — 三平台并行调用**

> 三个平台均返回 `prod_main_img` 商品主图（alicdn CDN），直接内联展示，无需额外图片搜索。
> 针对 TOP_BUYER_COUNTRIES[0]（主力买家国）调用，三平台同时执行。

**① Amazon（标杆平台，B端参考权重最高）**
```bash
accio-mcp-cli call global_hot_selling_products --json '{"query": "{{CATEGORY_INPUT}}", "platform": "amazon", "region": "{{TOP_BUYER_COUNTRIES[0]}}", "sorting_rule": "sales"}'
```
重点提取字段：
- `prod_main_img` / `title` / `price` / `sales_cnt_30d` / `rating_score` / `review_cnt` / `prod_url` / `prod_attribute`
- `positive_tag` → 消费者高频好评标签（直接反映买家在意什么）
- `negative_tag` → 消费者高频差评标签（代表市场痛点和供应商机会）
- `amz_search_trend` → 亚马逊搜索趋势方向

**② Temu（性价比端，走量最大，代表大众需求）**
```bash
accio-mcp-cli call global_hot_selling_products --json '{"query": "{{CATEGORY_INPUT}}", "platform": "temu", "region": "{{TOP_BUYER_COUNTRIES[0]}}", "sorting_rule": "sales"}'
```
重点提取字段：
- `prod_main_img` / `title` / `price` / `sales_cnt_30d` / `prod_url`
- 关注：价格带（Temu 代表市场价格下限）/ 款式款型（大众偏好的视觉风格）

**③ TikTok Shop（内容电商，代表社媒驱动的新兴需求）**

> ⚠️ TikTok MCP 对泛品类词（如 `christmas decoration`、`home decor`）容易返回 `error_info: "failed"`。
> 必须使用**具体品类词**（如 `gnome`、`wreath`、`ornament`、`outdoor sofa`），分品类逐一查询。

```bash
# 不能用泛词，必须用具体品类词
accio-mcp-cli call global_hot_selling_products --json '{"query": "{{具体子品类词}}", "platform": "tiktok", "region": "{{TOP_BUYER_COUNTRIES[0]}}", "sorting_rule": "sales"}'
```

若第一个词返回 `error_info: "failed"`，换另一个具体子品类词重试，最多尝试 3 个词。

> ⚠️ **图片 URL 必须完整输出，不能截断**：TikTok 图片 URL 较长（含 UUID），截断后变成 404。
> 取 `prod_main_img` 时必须取完整字符串，不能用 `[:80]` 等截断操作。

重点提取字段：
- `prod_main_img`（**完整 URL，不截断**）/ `title` / `price` / `sales_cnt_30d` / `prod_url`
- `tt_relate_video` → 关联视频数（数值越高，内容传播力越强）
- `tt_relate_author` → 关联达人数（代表 KOL 带货热度）

**图片获取与校验规则**

**⚠️ 图片URL必须来自本次MCP实时调用的返回值**
- 严禁使用任何历史缓存、上下文记忆或对话历史中的图片URL
- 每次生成报告必须重新调用 `global_hot_selling_products`，取当次返回的 `prod_main_img`
- MCP返回的URL有时效性，跨对话复用会导致404失效

**优先：直接使用本次MCP返回的 `prod_main_img`**
- 字段有值且URL以 `http` 开头 → 直接内联展示
- 字段为空 / URL不以 `http` 开头 / 经验证返回404 → 进入降级流程

**降级：执行 web_search 图片搜索**

适用场景：`prod_main_img` 为空或图片加载失败（TikTok 平台图片尤其容易出现此问题）

```
web_search(
  image=true,
  query="[CATEGORY_INPUT] [热销品具体款式词] product 2025"
)
示例：outdoor furniture hanging egg chair product 2025
示例：outdoor sofa rope weave aluminum frame product 2025
```

**搜索词规范**：
- 必须包含品类主词（如 outdoor furniture）
- 必须包含具体款式词（如 hanging egg chair / rope weave sofa），不能只搜品类主词
- 不加品牌名，避免搜出无关品牌图片

**图片校验过滤（取图前必须执行，过滤噪音）**：

```
对每张候选图片，判断以下条件，全部通过才可使用：
① 图片标题/alt文本 包含品类关键词（如 outdoor / furniture / sofa / chair 等）→ 通过
② 图片来源域名 不是以下噪音来源：pinterest引导页、广告落地页、新闻配图、无关电商 → 通过
③ 图片 URL 后缀 为 .jpg / .png / .webp → 通过（排除 .gif / .svg / base64 等）
④ 图片标题/来源 不含明显无关词（如 medicine / food / fashion / clothing 等）→ 通过

任一条件不通过 → 跳过该图，取下一张候选
所有候选图片均不通过 → 不输出图片，只输出文字描述
```

**兜底**：
- `sales_cnt_30d` 为空 → 用 `rating_score` + `review_cnt` 作为热度参考
- 某个平台返回数据为空 → 该平台标注「暂无该市场数据」，不影响其他平台输出
- 三步均无合适图片 → 不输出图片，不强行附图

**web_search 补充因子**（根据选取的因子ID对应检索）：

| 因子 | 搜索指令示例 |
|------|------------|
| F1 流行元素 | `"[CATEGORY_INPUT]" trend 2025 color style material forecast` / `site:wgsn.com OR site:mckinsey.com [CATEGORY_INPUT] trend` |
| F3 社媒种草 | `TikTok [CATEGORY_INPUT] trending 2025` / `Pinterest [CATEGORY_INPUT] popular` |
| F4 节庆日历 | 内部固定日历（见附录），结合 TOP_BUYER_COUNTRIES 过滤 |
| F5 赛事日历 | `major sports events 2025 2026 calendar` |
| F6 气候信号 | `[CATEGORY_INPUT] seasonal demand climate 2025` |
| F8 新材料/工艺 | `[CATEGORY_INPUT] new material technology innovation 2025 [行业专属来源]` |
| F9 成分趋势 | `[CATEGORY_INPUT] trending ingredient 2025 beauty personal care` |
| F10 原料价格 | `[原料名] price trend 2025 forecast` |
| F11 展会前瞻 | `[行业] trade show 2025 2026 exhibition calendar` |
| F12 政策法规 | `[CATEGORY_INPUT] regulation certification requirement [目标国] 2025` |
| F13 ESG | `[CATEGORY_INPUT] sustainability ESG regulation 2025` |
| F14 渠道政策 | `TikTok Shop Amazon policy [CATEGORY_INPUT] 2025` |

#### 通路 B · 全 web_search

同上搜索指令，全部通过 web_search 执行，每条数据标注来源名称及发布时间。
