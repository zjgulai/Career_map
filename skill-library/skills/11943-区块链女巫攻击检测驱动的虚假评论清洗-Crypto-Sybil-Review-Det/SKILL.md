## 输入 / 输出契约

**输入**：评论文本、评论者账号及其行为指纹（注册时间、历史评论量、评论时间戳分布），按评论与账号粒度；需要能与同类账号群作对比的样本量。

**输出**：识别出的异常账号群、句法指纹与时间模式证据，以及可提交平台的举报证据包，供申诉与合规团队使用。

## 执行步骤

1. 采集评论与账号行为数据
2. 提取句法指纹与时间模式特征
3. 按女巫攻击特征聚类识别异常账号群
4. 统计可举证的异常模式
5. 生成举报证据包并提交平台

## 边界与不做

- 评论样本量很小、没有可对比账号群时，先人工核查更划算。
- 本技能产出异常识别与证据材料，不保证平台受理结果。
- 证据只能用于平台举报与申诉，不得用于公开指控或报复性操作。
