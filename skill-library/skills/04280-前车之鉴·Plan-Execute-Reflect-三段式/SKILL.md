# 前车之鉴·Plan-Execute-Reflect 三段式

> 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行。适用问题形态：项目规划 / 目标分解 / 多步骤任务执行 / 复盘改进。

## 何时用

- 任务涉及多个阶段和依赖关系
- 需要在执行中动态调整计划
- 希望在完成后沉淀可复用的经验

本技能是**选型图纸 + 相位纪律模板**：用于①给新任务选定执行形态；②设计 subagent / workflow / goal 派工时套用相位结构（checkpoint 做验收门、stop_condition 做终止判据、loop_back 做回环路径）。

## 五链对照（先选对形态）

| 链 | 定位 |
|---|---|
| xmind-chain-react | Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务 |
| xmind-chain-tot | Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径 |
| xmind-chain-cot-critic | 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务 |
| xmind-chain-research | 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论 |
| xmind-chain-per | 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行 | **←本链**

## 本链 4 相位纪律

| 相位 | 输入 → 输出 | 检查点 | 停止/回环 | 关联模型 |
|---|---|---|---|---|
| 1. 目标设定（Goal Setting） | 模糊目标描述 → 结构化目标：{清晰目标, 成功标准, 关键障碍, 资源约束, 完成时间} | 将模糊目标转化为清晰可执行的目标定义。WOOP框架：愿望→结果→障碍→计划。每个目标必须有：1) 成功标准（可量化） 2) 时间边界 3) 资源约束 4) 最大障碍 | 停止：目标满足SMART：具体/可测量/可达成/相关/有时限 — | 框架思维_核心功能解析与高效 |
| 2. 计划制定（Planning） | 结构化目标 + 可用资源 → 执行计划：{任务列表（有序）, 每个任务的输入/输出/验收标准, 关键路径, 风险点} | 将目标分解为执行计划。分解原则：MECE（互斥完整），按依赖关系排序，每个任务有明确负责人/工具和验收标准 | 停止：计划覆盖所有达成目标所需的任务，无遗漏 — | 框架思维_核心功能解析与高效 |
| 3. 执行（Execute） | 执行计划 + 当前执行状态 → 执行日志：{完成任务, 实际结果, 偏差记录, 需要调整的后续任务} | 按计划执行，同时监控偏差。每完成一个任务：1) 标记完成 2) 记录实际结果 vs 预期 3) 识别影响后续任务的新信息 | 停止：所有任务完成 OR 遇到阻塞需要重规划 →回环至 decompose | 事后总结_并非终点_而是认知 |
| 4. 反思复盘（Reflect） | 执行日志 + 原始目标 → 复盘报告：{完成度, 偏差分析, 可复用经验, 根本原因, 改进行动} | 结构化复盘：1) 目标达成情况 2) 计划和执行的偏差及原因 3) 成功的可复用经验 4) 失败的根本原因 5) 下次改进点 | 停止：三个层次都有覆盖：行为层/系统层/认知层 — | 事后总结_并非终点_而是认知 |

## 落地用法

1. **编排派工**：把上表转成 subagent/workflow 的执行步骤；每相位产出必须先过检查点再进下一相位；触发回环条件时显式回到目标相位，不要静默重试。
2. **运行时纪律**：正在执行的任务陷入停滞时，对照当前相位的 stop_condition 判断是「该停」还是「该回环」，避免无限循环。
3. **关联模型深化**：各相位关联模型的完整推理协议用 xmind-gateway 的查询配方读取（四层结构 system_prompt 可直接注入对应相位执行者）。

## 何时不用 / 转诊

- 纯推理无外部交互 → xmind-chain-cot-critic；要工具交互迭代 → xmind-chain-react
- 多方案并行探索 → xmind-chain-tot；系统性多源研究 → xmind-chain-research
- 多阶段项目管理 → xmind-chain-per；单步低风险任务直接做
