# Deliverable revision

Identify the latest artifact and the requested delta from conversation context. Open supplied local files only through available host capabilities. Record preserve/change/exclude requirements and requested final location.
Preserve the existing artifact's language and intentional mixed-language sections unless the user requests translation or a language change. Exporting, reformatting or fixing images is not permission to translate. New or rewritten buyer-facing copy follows the user's explicit requested copy language; only absent such a request may the target audience supply the default. A marketplace does not override a requested draft language. New change summaries, evidence explanations, risks and next steps follow the user's established conversation language, even when the revised copy uses another language, unless the user explicitly requests the whole document in that language. Keep original keywords, brands, ASINs, URLs and machine-facing schema keys intact; localize human-facing labels without changing required schema. For example, preserve German listing copy for a Chinese-speaking user while describing revisions in Chinese.
Do not produce a new approval memo for "make this PDF", "keep format and images" or "mark changes on the box".
When the user requests only already-collected data and blank missing values, do not start supplementary retrieval or fill unknown cells with guesses. Preserve actual empty cells and existing workbook images, sheets and formatting unless changes were requested.
Before bulk operations, validate a representative preview against the user's constraints. For image edits: identify immutable product shape, logo, components and proportions. Use the original image as reference; if fidelity cannot be verified, label the output a concept draft and do not claim preservation.
Place requested annotations on the actual image regions, with readable callouts; a separate paragraph does not satisfy an on-image annotation request.

For HTML reports, package image assets with the file or embed them. Render the actual deliverable and check every referenced image loads, including transferred-file use where applicable. Verify spreadsheet sheet names, columns, row count and requested formulas/formatting. Confirm PDF language, page coverage and readability.
A filesystem existence check does not establish image fidelity or content correctness. If rendering is unavailable, report file creation and verification status separately.
On "none of the pictures displays", inspect paths, URLs and actual render errors; do not invent a cause from the symptom. Preserve source attribution necessary to avoid misleading claims even when shortening visible methodology.
Return the openable artifact plus concise changed/preserved/remaining items. No "completed" when only an internal progress note or file structure has been produced.
External publication remains out of scope. Local exports must never be presented as a listing, sent inquiry or installed automation.
