# Skill: 知识库版本控制系统

## ① 解决的问题

知识库运营面临"产品规格迭代后旧知识污染Agent答复导致合规风险"——知识库版本控制用Git式分支管理隔离知识变更，知识污染事故归零，合规审计追溯时间从2天缩至15分钟

## ③ 业务应用场景

业务问题： - 知识库运维人员误删FDA孕妇禁用成分库（含2847条规则），导致系统推荐禁用产品给孕妇 - 发现时已影响3小时，订单风险暴露

## 输入 / 输出契约

**输入**：需知识库的变更记录与操作日志（操作人、时间戳、SQL 语句、影响行数）、快照频率与存储预算，库级、表级、行级粒度。

**输出**：产出版本快照与审计日志、恢复方案（卡页记录恢复时间 15 分钟、恢复准确率 100%、影响订单从 3000 单降至 50 单），供知识库运维与合规审计使用。

## 执行步骤

1. 做知识库增量快照，按固定频率自动执行
2. 记录操作人、时间戳、语句与影响行数
3. 配置库级、表级、行级三层回滚能力
4. 定位污染发生的时间点
5. 按最近快照恢复到目标版本并核对影响范围

## 边界与不做

- 知识库几乎不变更或数据可随时重建时，快照与审计体系成本过高
- 只做版本控制与恢复，不判断知识内容本身是否正确
- 审计日志与快照含业务数据与操作人信息，须限定访问权限
