## 输入 / 输出契约

**输入**：待上架视频文件与字幕或口播文本（需具备 ASR 转录能力），画面抽帧清单（产品宣称截图、竞品 LOGO 出现位置），以及背景音乐音轨信息。

**输出**：带违规时间戳的合规预筛结果：违禁词位置、画面违规点与背景音乐版权风险，附一键修复建议，供内容运营上架前改稿复检。

## 执行步骤

1. 准备待上架视频，并转录出字幕与口播文字用于词级检测
2. 按画面内容检测产品宣称截图与竞品 LOGO 是否出现
3. 核对背景音乐版权归属与授权范围
4. 汇总违规时间戳与具体违规点并输出修复建议
5. 改稿后复检确认违规项清零
