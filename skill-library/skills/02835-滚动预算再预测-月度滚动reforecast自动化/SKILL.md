# Budget Reforecast Rolling — 滚动预算再预测（月度滚动reforecast自动化）

## ① 解决的问题

财务团队面临"静态年度预算在电商高波动环境下快速失效导致资金决策失准"——月度滚动预测比静态预算准确率提升40%，年化减少资金错配损失15-25万元

## ② 核心算法逻辑

静态年度预算在电商高波动环境下快速失效。滚动预测（Rolling Forecast）每月自动更新未来36个月的收入/成本预测：用Prophet时序模型更新销量预测，结合实际费率更新成本模型，输出最新的全年预计利润。

## 输入 / 输出契约

**输入**：历史销量与收入序列、成本费率与费用结构、当年度预算基线；粒度：按月，覆盖未来 36 个月的滚动窗口，输入需与实际财务台账口径一致。

**输出**：更新后的未来 36 个月收入与成本预测、最新全年预计利润及其与静态预算的差异说明，供财务做资金与投放决策。

## 执行步骤

1. 拉取历史销量与收入序列并校验口径
2. 用时序模型重估未来销量预测
3. 按最新费率与费用结构更新成本模型
4. 汇总出最新全年预计利润并对比原预算
5. 输出偏差说明与调整建议

## 边界与不做

- 数据不满足时不用：历史序列过短或费率口径未与财务对齐时，滚动预测会放大误差。
- 能力边界：产出的是预测与偏差说明，不自动改预算科目、不替代财务审批流程。
