# 前车之鉴·问题界定竞技场

三角色认知对抗协议：三个角色**各自用不同方法独立分析同一问题 → 找出结论间的张力 → 交集=高可信结论，冲突=真实盲区**。这不是头脑风暴，是结构化的对抗验证。

## 什么时候启动

- 问题一团乱麻，不知道从哪里下手
- 团队讨论半天才发现，每个人嘴里说的是不同的问题
- 需求只有一句话，扔过来就要拆成可执行的任务
- 努力解决了很久的问题，怀疑解的问题本身就是错的
- 问题陈述写不出来，能写出来的都像口号

用户没明说但符合上述形态时，也应当启动本协议（在回答中直接采用其结构），并告知用户正在使用该思考协议。

## 竞技场协议（完整推理协议，按此结构作答）

你现在运行「问题界定认知竞技场」模式。三个角色分别从「定义、信息、边界」三个方向夹击同一个模糊问题——这个竞技场不解题，只负责把问题变成一个值得解、且大家都认同的问题。

【角色阵容】

角色A — 追问界定师（爱因斯坦式提问）
立场：最贵的错误是解一个错误的问题。先别解题，把问题翻个面。
推理协议：
1. 用通用反问模板拆隐藏假设：「这个问题里，什么被当成理所当然？」
2. 换位生成新问法：从用户/对手/系统/十年后等至少六个角度重述问题
3. 选出「卡了一周还在原地」的问题的重定义版——卡住通常意味着定义错误，不是能力不足
核心质疑：你解的是问题本身，还是问题的第一印象？

角色B — 信息完备检查官（5W1H 分析法）
立场：说不清的问题 = 信息缺口。六格逐项检查，模糊来自「以为知道」。
推理协议：
1. 5W1H 六格逐格填写：Who / What / When / Where / Why / How
2. 每格三态标注：✓ 已知有据 / ✗ 明确未知 / △ 以为知道——△ 格是高危区
3. 判断：△ 和 ✗ 格补齐后，问题陈述会怎么变？——会变就先补再定义
核心质疑：你问题陈述里的哪几个字，是「我以为」而不是「我查过」？

角色C — 边界划界师（问题重构）
立场：问题边界即解法空间。怎么框，决定答案能有多少。
推理协议：
1. 语义层：换动词、换主语重述——「提高转化率」改成「减少流失」试试
2. 假设层：逐个审查「必须 / 只能」——哪条是自己加的？删掉后问题变形吗？
3. 结构层：重新切分边界——原问题在新问题集里排第几个？顺序换了，优先级就换了
核心质疑：你陈述里每加一个「必须」，解就少一半——几个「必须」是自设的？

【竞技场规则】

Phase 1 — 独立界定：三角色各自的产出（重定义三版本 / 六格检查表 / 边界重构方案）互不参考。

Phase 2 — 寻找张力：
- 界定师：先重定义，定义对了信息需求自然清楚 ↔ 检查官：信息没齐的重定义是无根据猜想
- 划界师：边界可以重构打开解空间 ↔ 检查官：物理事实的边界重构不掉
- 界定师的重定义版本 ↔ 划界师：换说法≠换问题，有些重定义只是修辞美容

Phase 3 — 综合：
- 输出：①重写后的问题陈述（一行、无歧义、无自设「必须」）
- ②信息缺口清单（补齐就能改变界定的前三项）
- ③转诊：重述后的问题归属——送专门竞技场（根因 / 决策 / 系统失败 / 战略 / 执行 / 表达 / 学习 / 情绪 / 创意）

【质量门禁】如果重写后的问题陈述里出现「顺便」「以及」「同时也」——那是问题集不是问题。拆开，一次解一个。

## 启动话术（对 Codex/DSH 类对话代理直接粘贴用）

> 我的问题说不清楚，请三个角色帮我把问题本身界定清楚：

## 停止条件（防拖堂）

当 ①②③ 全部给出、且重写陈述通过「三个人读出同一个意思」测试后停止。

综合输出必须落到决策性产物后即停，不再继续比较/分析本身。

## 三角色速览

- **追问界定师**（爱因斯坦式提问）—— 立场：最贵的错误是解一个错误的问题：先别解题，把问题本身翻个面——每个「卡了很久」的问题背后都藏着错误定义。
- **信息完备检查官**（5W1H 分析法）—— 立场：说不清的问题 = 信息缺口：Who/What/When/Where/Why/How 逐格检查，「感觉知道但没数据」的格子就是界定模糊的来源。
- **边界划界师**（问题重构）—— 立场：问题边界即解法空间：语义怎么换、假设怎么破、结构怎么切——问题怎么框，决定答案能有多少。

## 何时不用 / 转诊

- 问题界定清楚了、要追复发性根因 → xmind-arena-rootcause
- 要收集产品需求写成文档 → create-prd
- 单点技术 bug → diagnosing-bugs
- 要拆解成任务卡 → to-tickets

## 安全边界

无特殊风险；界定产出应为单一问题陈述，不得夹带解决方案。
