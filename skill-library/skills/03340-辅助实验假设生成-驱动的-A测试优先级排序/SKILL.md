# LLM 辅助实验假设生成 — AI 驱动的 A/B 测试优先级排序

## ① 解决的问题

产品经理面临"实验假设来源于个人经验导致覆盖面窄且漏掉高价值机会"——LLM基于历史实验数据生成假设将候选假设多样性提升300%，年化发现更多增长机会增收20-40万元

## ② 核心算法逻辑

传统 A/B 测试假设生成依赖人工经验，存在认知偏差（确认偏误、可得性启发）和覆盖盲区。LLM 辅助假设生成通过结构化 Prompt 框架，让大语言模型基于业务数据、用户行为洞察和学术研究，系统生成实验假设并进行多维度优先级评分。

## ③ 业务应用场景

场景1：婴儿推车 Listing 优化——LLM 生成 15 个实验假设并排序 - 业务问题：运营团队每月只能跑 3 个 AB 测试，不知道优先测哪个 - 数据要求：过去 6 个月实验历史（假设 + 结果）、用户评论 top 100、竞品 Listing 截图描述 - 方法：DeepSeek/GPT-4o Prompt 生成假设，ICE 自动评分，输出优先级排行榜 - 预期产出：生成 15 个假设，Top-3 假设（ICE > 7）验证成功率历史上达 67%（vs 随机 30%） - 业务价值：实验成功率翻倍，每季度有效迭代从 3 次增至 5 次，GMV 改善 +20 万元/季度
场景2：复购场景假设生成——从 VOC 到实验设计自动化 - 业务问题：用户评论中藏着大量优化信号，但人工提炼效率低 - 数据要求：Amazon 评论 200 条 + 店铺内部搜索词报告 + 竞品 Q&A - 方法：LLM 多轮 Prompt（角色：资深 CRO 专家），从用户痛点直接推导实验假设 - 预期产出：10 个基于 VOC 的假设，覆盖主图/文案/价格/Bundle 4 个维度 - 业务价值：VOC→实验的转化效率提升 5×，假设质量更贴近用户真实需求
**三轨验证**： - 成本：DeepSeek API 费用极低（1000 假设 < 5 元），人工审核 2 小时 - 合规：假设生成不涉及用户 PII，输入为聚合数据；LLM 输出需人工审核防止 AI 幻觉 - 风险：LLM 可能生成 overfit 于训练数据的假设（重复已知结论），需强制要求"新颖性"条件

## 输入 / 输出契约

**输入**：过去 6 个月实验历史（假设 + 结果）、用户评论 top 100、竞品 Listing 描述；VOC 场景为 Amazon 评论 200 条 + 店铺内部搜索词报告 + 竞品 Q&A；输入均为聚合数据，不含用户 PII。

**输出**：批量实验假设与 ICE 评分排序（卡页示例：生成 15 个假设，Top-3 假设 ICE 大于 7、历史验证成功率 67% 对比随机的 30%；VOC 场景产出 10 个假设，覆盖主图、文案、价格、Bundle 四个维度）。

## 执行步骤

1. 汇总实验历史、用户评论与竞品素材并做聚合整理
2. 用结构化 Prompt 让 LLM 生成候选实验假设
3. 用 ICE 框架对假设自动评分
4. 输出假设优先级排行榜与效应量预估
5. 人工审核假设并加平台规则约束后进入实验排期

## 边界与不做

- 何时不用：已有明确假设、只需设计实验时用 A/B 实验设计类技能；没有历史实验数据与用户反馈素材时生成质量下降。卡页第 7 段无代码模板，落地需另行获取代码。
- 能力边界：只生成与排序假设，不执行实验、也不保证假设成立；LLM 可能生成过拟合于已知结论的假设，需强制新颖性条件，输出须人工审核以防幻觉。
- 合规边界：输入只用聚合数据、不涉及用户 PII；LLM 输出必须人工审核，防止 AI 幻觉。
- 卡页数字（生成 15 个假设、Top-3 成功率 67% 对比 30%、每季度有效迭代从 3 次增至 5 次、年化 20-40 万元与 40-80 万元）为示例场景，不可直接外推。
