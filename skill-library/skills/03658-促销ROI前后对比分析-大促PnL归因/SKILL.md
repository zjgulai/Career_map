## 输入 / 输出契约

**输入**：促销 SKU 与对照 SKU 的促销前后销售与利润数据，含时间、SKU 分组、销量与促销标记，粒度到 SKU 与周或日。

**输出**：促销净增量销售额与利润贡献（剥离自然增长与渠道波动后），用于优化下次大促的预算分配。

## 执行步骤

1. 选定促销 SKU 与非促销对照 SKU
2. 对齐促销前后的时间窗口与统计口径
3. 以对照 SKU 为基准剥离自然增长与渠道波动
4. 算出促销净增量销售额与利润贡献
5. 输出预算再分配建议

## 边界与不做

- 找不到可比对照 SKU 或促销前后窗口不一致时不适用，增量会被高估
- 只做增量归因与建议，不代替大促预算审批与投放执行
- 对照 SKU 与统计口径须前后一致，否则结论不可比
