# Skill-RAG-CoT-Interleaved-Reasoning

## ① 解决的问题

合规团队面临多步骤决策推理依据不足——RAG-CoT交织推理每步有据可查，多跳准确率+28%，合规决策可审计，年化风险规避45万元

## 输入 / 输出契约

**输入**：待判断的合规多步决策问题，以及支撑推理检索的合规知识库文档（法规、标准与内部合规材料）；粒度：单个合规判断问题及其可检索文档库。

**输出**：带逐步出处的推理链与最终合规判断结论，每一步推理标注引用来源；用于合规决策的可审计与人工复核。

## 执行步骤

1. 把合规问题拆解为有序的多跳推理步骤
2. 每一步判断是否需要检索并取回证据
3. 在推理与检索之间交替推进并标注引用
4. 汇总各步结论形成合规判断
5. 输出带出处的推理链供审计复核

## 边界与不做

- 数据不满足时不用：没有可检索的合规知识库、或问题单步事实即可回答时，无需交织推理。
- 能力边界：只产出带出处的推理链与结论，不代替合规负责人做最终判责，也不补齐缺失的法规原文。
