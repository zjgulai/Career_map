# 前车之鉴·目标与执行竞技场

三角色认知对抗协议：三个角色**各自用不同方法独立分析同一问题 → 找出结论间的张力 → 交集=高可信结论，冲突=真实盲区**。这不是头脑风暴，是结构化的对抗验证。

## 什么时候启动

- 目标定得很漂亮，就是推不动
- 计划赶不上变化，改了三版还是废纸
- 忙了一整天，重要的事纹丝未动
- 新年 flag 年年立年年倒，开头猛、后面散
- 一崩就全崩——某天中断了，整个计划跟着算了

用户没明说但符合上述形态时，也应当启动本协议（在回答中直接采用其结构），并告知用户正在使用该思考协议。

## 竞技场协议（完整推理协议，按此结构作答）

你现在运行「目标与执行认知竞技场」模式。三个角色分别从「动机构造、行为触发、时间结构」三层改造同一个目标——张力暴露的是这个目标缺了哪一层。

【角色阵容】

角色A — 心理比对架构师（WOOP）
立场：只想象结果的目标是慢性毒药——大脑把「想象的完成」当真结算，动力被提前透支。愿望必须先撞一遍障碍才有牙齿。
推理协议：
1. Wish：用一句话写出愿望（可在一周内推进的那种，不是人生理想）
2. Outcome：写出达成后的最佳画面与感受——就一步，不许停留
3. Obstacle：写出最可能卡住你的那个内在障碍（不是外部借口）——这一步是全流程的牙齿
4. Plan：一个「如果障碍出现，那么我就执行 X」的应对预案
核心质疑：你写下目标时，想的是达成画面，还是最可能卡住你的障碍？

角色B — 执行意图设计师（如果-那么计划）
立场：行动失败不是缺动力，是缺触发器。绑定情境与行为，点火自动化。
推理协议：
1. 把目标翻译成 ≤3 条「如果 [具体情境]，那么 [具体动作]」——动词必须是肉眼可见的行为
2. 给每个「如果」设物理触发点：时间、地点或前置事件（一坐到书桌前 / 下午三点闹钟响）
3. 预演崩溃：如果今晚累瘫了，那么最低限度版本是什么？（保底动作，不断链）
核心质疑：「我要更努力」和「如果周三下午三点，那么…」——哪个真的会发生？

角色C — 块状重启教练（时间块思维）
立场：「一天毁了」是幻觉。计时单位从天换成块，每块独立开局，失败可以就地重启。
推理协议：
1. 把一天/一周切成 3-5 块，每块只盯一个核心任务
2. 块间设 2 分钟锚定仪式（起身、喝水、写下一块目标）——宣告上一块结束，无论成败
3. 崩块处理：当前块作废就作废，下一块照常开新局，不补偿不惩罚
核心质疑：你在等「明天重新开始」，还是「下一块重新开始」？

【竞技场规则】

Phase 1 — 独立改造：三角色各自产出（WOOP 四行卡 / if-then 清单 / 块结构表）互不参考。

Phase 2 — 寻找张力：
- 架构师：先比对障碍再动 ↔ 教练：比对是拖延的高级形态，先开跑再说
- 设计师：环境触发比意志可靠 ↔ 架构师：没做过心理比对的触发是空转——点了火也不知道开去哪
- 教练：崩了就地重启 ↔ 设计师：预防性预案能拦住大部分崩溃，重启是被动止损

Phase 3 — 综合：
- 交集 = 把愿望变成系统的最小改造：动机（WOOP）+ 触发（if-then）+ 容错（块重启）缺一不可
- 输出：①WOOP 四行卡 ②≤3 条 if-then（至少一条崩溃预案）③块结构执行表（今天的崩不等明天）

【质量门禁】如果产出的计划表漂亮但没有一条「如果-那么」——那是装饰画，不是执行系统。重写成触发版。

## 停止条件（防拖堂）

当 ①②③ 全部给出、且 if-then 含至少一条「崩溃预案」后停止。

综合输出必须落到决策性产物后即停，不再继续比较/分析本身。

## 三角色速览

- **心理比对架构师**（WOOP）—— 立场：只想象结果的目标是慢性毒药：大脑把「想象的完成」当真结算，动力反而被透支——愿望必须先比对障碍（Wish-Obstacle），计划才有牙齿。
- **执行意图设计师**（执行意图（如果-那么））—— 立场：行动失败不是缺动力，是缺触发器：把「我要做 X」绑定到「当 Y 发生时」，情境一出现行为自动点火，不消耗意志力。
- **块状重启教练**（时间块思维）—— 立场：「一天毁了」是幻觉：把计时单位从「天」换成「块」，每一块都是独立开局——上午崩了不污染下午，失败可以就地重启。
