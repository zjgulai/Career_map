# Inventory Write-Down Impairment — 库存减值准备计算（滞销品会计处理+税务）

## ① 解决的问题

财务团队面临"滞销母婴产品未及时计提减值导致资产虚高和税务风险"——自动减值识别和计算将税务处理及时性提升100%，年化税务节省5-15万元

## ② 核心算法逻辑

滞销母婴产品（过期奶粉/退时尚婴儿车）需要进行库存减值处理。减值准备计算模型：基于可变现净值（NRV）= 预计售价 完工成本 销售费用。当NRV < 账面成本时需计提减值，影响当期利润但可抵税。自动化识别滞销SKU并计算最优减值时机。

## 输入 / 输出契约

**输入**：滞销 SKU 的账面成本、预计售价、完工与销售费用（用于计算可变现净值），以及库龄与临期信息，粒度到 SKU 与批次。

**输出**：SKU 或批次级的减值准备金额、计提建议与税务处理时点，供财务做账与税务申报参考。

## 执行步骤

1. 筛出滞销、临期与退时尚库存
2. 按可变现净值等于预计售价减完工成本与销售费用逐项测算
3. 对比账面成本判断是否需要计提减值
4. 给出计提金额与最优计提时点建议

## 边界与不做

- 缺少预计售价或销售费用口径时不适用，可变现净值无法测算
- 只产出减值测算与建议，不代替账务处理、审计确认或税务申报
- 计提口径需与会计政策保持一致，不得为调节利润随意变更
