# 前车之鉴·CoT + Critic 验证链

> 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务。适用问题形态：复杂逻辑推理 / 多步骤分析 / 需要自我验证的结论 / 容错率低的决策。

## 何时用

- 推理步骤多于3步，容易出现中间错误
- 结论需要高置信度，错误代价大
- 需要区分事实和推断

本技能是**选型图纸 + 相位纪律模板**：用于①给新任务选定执行形态；②设计 subagent / workflow / goal 派工时套用相位结构（checkpoint 做验收门、stop_condition 做终止判据、loop_back 做回环路径）。

## 五链对照（先选对形态）

| 链 | 定位 |
|---|---|
| xmind-chain-react | Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务 |
| xmind-chain-tot | Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径 |
| xmind-chain-cot-critic | 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务 | **←本链**
| xmind-chain-research | 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论 |
| xmind-chain-per | 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行 |

## 本链 5 相位纪律

| 相位 | 输入 → 输出 | 检查点 | 停止/回环 | 关联模型 |
|---|---|---|---|---|
| 1. 问题分解（Decompose） | 原始复杂问题 → 子问题树：{子问题列表, 依赖关系, 求解顺序} | 将问题分解为互斥完整的子问题。每个子问题必须：1) 独立可解 2) 有明确答案格式 3) 按依赖关系排序 | 停止：所有子问题合起来完整覆盖原问题 — | 框架思维_核心功能解析与高效 |
| 2. 逐步推理（Chain-of-Thought） | 子问题 + 已知信息 → 推理链：每步格式 = {规则, 应用, 结论, 置信度, 依赖假设} | 对每个子问题进行深度推理。每步必须：1) 声明使用的推理规则 2) 区分「事实」和「推断」3) 给出置信度（高/中/低） | 停止：所有子问题有推理结论 — | 第一性原理_看透本质_高效破 |
| 3. 批判审查（Critic） | Phase 2 的完整推理链 → 批判报告：{发现的问题列表, 每个问题的严重程度, 修复建议} | 扮演严格的批判者，审查推理链。检查：1) 有没有逻辑跳跃？2) 关键假设是否成立？3) 有没有反例？4) 置信度低的步骤是否影响结论？ | 停止：没有严重问题 OR 所有严重问题已标注 — | 批判性思维工具包_3步拆解论 |
| 4. 修正推理（Revise） | Phase 2 推理链 + Phase 3 批判报告 → 修正后的推理链（标注哪些步骤被修改） | 根据 Critic 的报告修正推理。对每个被标注的问题：1) 承认原推理的问题 2) 重新推导 3) 说明修正了什么 | 停止：所有严重问题已被修复 →回环至 critique | 第一性原理_看透本质_高效破 |
| 5. 验证综合（Verify & Synthesize） | 修正后的推理链 → 最终结论：{核心答案, 关键假设, 整体置信度, 适用边界, 无效场景} | 综合验证后的推理链，输出最终结论。必须：1) 列出最终依赖的关键假设 2) 整体置信度评估 3) 结论的适用边界 | 停止：输出完整 — | 事后总结_并非终点_而是认知 |

## 落地用法

1. **编排派工**：把上表转成 subagent/workflow 的执行步骤；每相位产出必须先过检查点再进下一相位；触发回环条件时显式回到目标相位，不要静默重试。
2. **运行时纪律**：正在执行的任务陷入停滞时，对照当前相位的 stop_condition 判断是「该停」还是「该回环」，避免无限循环。
3. **关联模型深化**：各相位关联模型的完整推理协议用 xmind-gateway 的查询配方读取（四层结构 system_prompt 可直接注入对应相位执行者）。

## 何时不用 / 转诊

- 纯推理无外部交互 → xmind-chain-cot-critic；要工具交互迭代 → xmind-chain-react
- 多方案并行探索 → xmind-chain-tot；系统性多源研究 → xmind-chain-research
- 多阶段项目管理 → xmind-chain-per；单步低风险任务直接做
