# Skill-MemGPT-Virtual-Context-Management

## ① 解决的问题

运营 Agent 每季度重置上下文导致跨季度消费者偏好演变识别失效——引入虚拟上下文管理（层次化内外存储），Agent 跨会话记忆保留率从 0→85%，年化运营策略连续性收益提升12倍。

## ② 核心算法逻辑

SkillMemGPTVirtualContextManagement

## ③ 业务应用场景

业务问题： - 传统运营系统每季度重置分析上下文，导致跨季度趋势识别失效 - 消费者偏好演变（孕期→新生儿→幼儿）的连续性记忆丢失 - 营销策略无法基于12个月的累积洞察优化
数据要求： - 月度销售数据（SKU×地区×客群）：12×500×50 = 30万条记录 - 消费者反馈文本：月均5000条评价 - 库存/物流事件日志：日均2000条
量化产出： - 年度趋势识别准确率：从62%→89%（+27pp） - 跨季度营销ROI提升：从1.8→2.4倍（+33%） - 库存预测MAPE：从18%→11%（-39%） - 年度运营决策优化数：从4个→12个关键决策点

## 输入 / 输出契约

**输入**：月度销售数据（卡页示例为 SKU 乘地区乘客群的 12 个月约 30 万条记录）、消费者反馈文本（示例月均 5000 条评价）与库存物流事件日志（示例日均 2000 条）。

**输出**：由记忆支撑的长期结论与建议：卡页示例把年度趋势识别准确率从 62% 提升至 89%、跨季度营销 ROI 从 1.8 提升至 2.4 倍、库存预测 MAPE 从 18% 降至 11%。

## 执行步骤

1. 把月度销售、消费者反馈与库存物流日志整理成结构化记忆记录
2. 分层存放：工作上下文在内、长期记忆在外，按需检索回上下文
3. 用跨会话记忆支撑跨季度趋势识别与策略延续
4. 输出年度洞察与关键决策点建议
5. 定期整理与淘汰失效记忆，控制存储成本

## 边界与不做

- 数据不满足时不用：缺少跨期数据（例如只有单季度记录）时，跨会话记忆没有可延续的内容。
- 能力边界：本卡产出记忆管理机制与跨期结论，不替代经营策略决策，也不含底层向量库的运维。
- 记忆库中的消费者偏好与反馈属个人信息，须支持按遗忘权删除并限制访问范围。
