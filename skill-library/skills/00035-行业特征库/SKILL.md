## 行业1：机械设备 / 工业零件

| 维度 | 特征 |
|------|------|
| **必需认证** | CE（欧盟强制）、ISO 9001/14001、部分品类需ATEX防爆认证 |
| **买家关注点** | 技术参数精度、产能效率、售后响应速度、备件可得性、安装指导 |
| **内容策略** | 以B2B工业框架展示：车间实拍、产线视频、技术参数表、CAD图纸、第三方检测报告；强调OEM/ODM能力 |
| **价格敏感度** | ⭐⭐ 中等偏低——更看重性价比（性能/价格比）而非绝对低价 |
| **典型MOQ** | 1-5台（大型设备可单台起订）；配件类50-500件 |
| **决策周期** | 长（2-6个月），多轮技术沟通 |
| **关键展会** | 汉诺威工业博览会(Hannover Messe)、广交会机电展区、CIMT中国国际机床展 |

## 行业2：电子消费品 / 3C

| 维度 | 特征 |
|------|------|
| **必需认证** | FCC（美国）、CE/RoHS（欧盟）、UL（安全）、Bluetooth SIG（蓝牙产品）|
| **买家关注点** | 外观工业设计、功能创新点、包装品质、用户评价、退换货率、交货速度 |
| **内容策略** | 视觉营销为核心：场景化产品图、开箱视频、功能对比图、KOL评测引用；重视Review数量与评分 |
| **价格敏感度** | ⭐⭐⭐ 中等——价格竞争激烈但差异化可溢价 |
| **典型MOQ** | 100-1000件（标品可更低） |
| **决策周期** | 短-中（1-4周），趋势驱动型采购 |
| **关键展会** | CES（拉斯维加斯）、环球资源电子展、IFA柏林、香港电子展 |

## 行业3：家居 / 家具

| 维度 | 特征 |
|------|------|
| **必需认证** | CE、SGS检测报告、BSCI社会责任审核、FSC（木质产品）、CARB（美国甲醛标准） |
| **买家关注点** | 设计风格匹配、材质环保性、包装防护（大件物流损耗）、定制能力（尺寸/颜色/面料） |
| **内容策略** | 生活场景化展示为主：实景家居空间图、3D渲染效果图、搭配方案；包装方案需单独展示（防震/防潮/体积优化）|
| **价格敏感度** | ⭐⭐ 中等偏低——设计感和品质可支撑溢价 |
| **典型MOQ** | 50-200件（定制品MOQ较高）；小件家居100-500件 |
| **决策周期** | 中（2-8周），需确认样品 |
| **关键展会** | 广交会家居展区、科隆国际家具展(imm)、高点家具展(High Point)、迪拜Index |

## 行业4：服装 / 纺织

| 维度 | 特征 |
|------|------|
| **必需认证** | OEKO-TEX Standard 100、BSCI、GOTS（有机纺织）、GRS（再生纤维）、AZO Free（偶氮染料） |
| **买家关注点** | 面料成分/克重/手感、尺码精准度（尤其欧美市场）、色牢度、交期准时、小单快反能力 |
| **内容策略** | 时尚趋势导向：当季流行色系、面料科技故事、穿搭场景图、尺码对照表；工厂产能和快反能力展示 |
| **价格敏感度** | ⭐⭐⭐⭐ 较高——同质化竞争激烈，价格是关键决策因素 |
| **典型MOQ** | 100-500件/款/色（快时尚客户期望更低MOQ） |
| **决策周期** | 短-中（1-3周），强季节性 |
| **关键展会** | Canton Fair纺织服装展区、Intertextile面料展、Magic Show（拉斯维加斯）、Première Vision巴黎 |

## 行业5：美妆 / 个护

| 维度 | 特征 |
|------|------|
| **必需认证** | FDA（美国OTC/化妆品）、EU Cosmetics Regulation 1223/2009（欧盟CPNP注册）、GMPC/ISO 22716、MSDS |
| **买家关注点** | 成分安全性（无动物测试/纯素/无防腐剂趋势）、包装合规（成分标注INCI名称）、保质期、最小起订量 |
| **内容策略** | 成分故事+安全背书：成分功效解析、实验室/洁净车间展示、第三方检测报告、Before/After效果对比；包装定制能力是加分项 |
| **价格敏感度** | ⭐⭐ 中等偏低——品牌溢价空间大，但白牌市场价格竞争激烈 |
| **典型MOQ** | 500-3000件（OEM）；ODM/自有品牌可更低 |
| **决策周期** | 中（3-8周），需样品测试+成分审核 |
| **关键展会** | Beautyworld Middle East、Cosmoprof博洛尼亚、In-Cosmetics Global、广交会美妆展区 |

## 行业6：食品 / 保健品

| 维度 | 特征 |
|------|------|
| **必需认证** | FDA注册（美国）、HACCP/ISO 22000（食品安全体系）、Organic认证（USDA/EU Organic）、Halal/Kosher（特定市场）|
| **买家关注点** | 保质期余量（出货时≥2/3）、冷链物流能力、标签合规（营养成表/过敏原标注）、批次可追溯性 |
| **内容策略** | 安全+溯源为核心：生产基地GMP认证展示、原料溯源链、营养成分检测报告、包装标签合规模板；保质期管理方案 |
| **价格敏感度** | ⭐⭐ 中等偏低——食品安全溢价高，但大宗原料价格敏感 |
| **典型MOQ** | 500-5000件（标品）；大宗原料按吨计 |
| **决策周期** | 中-长（4-12周），涉及标签审核和进口备案 |
| **关键展会** | SIAL巴黎/上海、Anuga科隆、FIC中国国际食品添加剂展、Natural Products Expo West |

## 行业7：母婴 / 玩具

| 维度 | 特征 |
|------|------|
| **必需认证** | CPSIA（美国强制）、EN71（欧盟玩具安全）、ASTM F963（美国玩具标准）、CCC（中国强制）、REACH（化学物质限制）|
| **买家关注点** | 安全合规是第一门槛（无商量余地）、材质无毒证明、小零件窒息风险测试、年龄适配标注、包装安全警示 |
| **内容策略** | 安全认证前置展示：检测报告/认证证书放在首屏、产品安全测试过程可视化（拉力/跌落/化学检测）、年龄段适配说明 |
| **价格敏感度** | ⭐⭐ 低——安全合规溢价高，买家不会在安全项上压价 |
| **典型MOQ** | 500-2000件（标品玩具）；定制品MOQ更高 |
| **决策周期** | 长（6-16周），认证审核环节耗时 |
| **关键展会** | 纽伦堡玩具展(Spielwarenmesse)、香港玩具展、ABC Kids Expo、Canton Fair玩具展区 |

---

## 行业8：汽配 / 摩配

| 维度 | 特征 |
|------|------|
| **必需认证** | E-Mark（欧盟车辆零部件）、DOT（美国交通部）、ISO/TS 16949（汽车行业质量体系）、AMECA（美国安全件）|
| **买家关注点** | OEM编号精准匹配、技术图纸公差、材质报告、批量一致性（PPM不良率）、包装防锈处理 |
| **内容策略** | 技术导向：OEM编号对照表、爆炸图/装配图、技术图纸标注、材质检测报告、适配车型清单；强调IATF 16949体系 |
| **价格敏感度** | ⭐⭐⭐ 中等——OEM件价格透明度较高，售后市场(AM)有溢价空间 |
| **典型MOQ** | 100-1000件（标准件）；大型总成件可单件起订 |
| **决策周期** | 中-长（4-12周），需样件验证+小批量试装 |
| **关键展会** | Automechanika法兰克福/上海、AAPEX（拉斯维加斯）、Canton Fair汽配展区、PAACE美洲汽配展 |
