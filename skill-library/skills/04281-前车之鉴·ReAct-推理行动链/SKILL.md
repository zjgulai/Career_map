# 前车之鉴·ReAct 推理行动链

> Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务。适用问题形态：信息搜集+推理 / 验证假设 / 迭代求解 / 工具调用规划。

## 何时用

- 任务需要搜集信息然后推理，而非纯粹推理
- 答案不确定，需要行动后观察结果再调整
- 有多个可选工具/方法，需要动态选择

本技能是**选型图纸 + 相位纪律模板**：用于①给新任务选定执行形态；②设计 subagent / workflow / goal 派工时套用相位结构（checkpoint 做验收门、stop_condition 做终止判据、loop_back 做回环路径）。

## 五链对照（先选对形态）

| 链 | 定位 |
|---|---|
| xmind-chain-react | Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务 | **←本链**
| xmind-chain-tot | Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径 |
| xmind-chain-cot-critic | 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务 |
| xmind-chain-research | 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论 |
| xmind-chain-per | 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行 |

## 本链 5 相位纪律

| 相位 | 输入 → 输出 | 检查点 | 停止/回环 | 关联模型 |
|---|---|---|---|---|
| 1. 意图澄清（Intent Clarification） | 用户的原始任务描述 → 结构化任务规范：{目标, 成功标准, 约束, 已知信息} | 苏格拉底式追问：在开始行动前，确认任务的真实意图。追问：1) 最终要得到什么？2) 成功的标准是什么？3) 有哪些已知约束？ | 停止：任务目标和成功标准已被明确确认 — | 爱因斯坦式提问_5步重新定义 |
| 2. 推理（Reason） | 来自 Phase 1 的结构化任务规范 → 行动计划：{行动序列, 每步预期输出, 判断标准} | 基于已知信息，推导：1) 什么信息/行动是必须的？2) 推断顺序是什么？3) 预期结果是什么？ | 停止：行动计划覆盖了所有必要步骤 — | 第一性原理_看透本质_高效破 |
| 3. 行动（Act） | 来自 Phase 2 的行动计划，执行第 N 步 → 行动结果：{原始输出, 工具/方法, 执行状态} | 执行第一个行动。行动前声明：1) 这一步的目标是什么？2) 使用什么工具/方法？3) 预期返回什么格式？ | 停止：行动已执行，有明确的输出（成功/失败/需要追问） — | 事后总结_并非终点_而是认知 |
| 4. 观察（Observe） | 来自 Phase 3 的行动结果 → 观察报告：{匹配度, 新发现, 计划修正（如需）, 是否继续循环} | 分析行动结果：1) 结果是否符合预期？2) 发现了什么新信息？3) 需要修正计划吗？4) 是否满足停止条件？ | 停止：任务完成 OR 达到最大迭代次数 OR 无法继续 →回环至 plan | 事后总结_并非终点_而是认知 |
| 5. 综合输出（Synthesize） | 所有历史 Reason-Act-Observe 记录 → 最终结论：{核心答案, 推理过程, 置信度, 局限说明} | 将所有观察和行动结果综合为最终答案。格式：结论→依据→局限边界→下一步建议。 | 停止：用户目标已被满足 — | 金字塔原理_理清逻辑_高效表 |

## 落地用法

1. **编排派工**：把上表转成 subagent/workflow 的执行步骤；每相位产出必须先过检查点再进下一相位；触发回环条件时显式回到目标相位，不要静默重试。
2. **运行时纪律**：正在执行的任务陷入停滞时，对照当前相位的 stop_condition 判断是「该停」还是「该回环」，避免无限循环。
3. **关联模型深化**：各相位关联模型的完整推理协议用 xmind-gateway 的查询配方读取（四层结构 system_prompt 可直接注入对应相位执行者）。

## 何时不用 / 转诊

- 纯推理无外部交互 → xmind-chain-cot-critic；要工具交互迭代 → xmind-chain-react
- 多方案并行探索 → xmind-chain-tot；系统性多源研究 → xmind-chain-research
- 多阶段项目管理 → xmind-chain-per；单步低风险任务直接做
