# LLM-Assisted Experiment Hypothesis Generation — LLM 辅助实验假设生成与优先级排序

## ① 解决的问题

产品经理面临"每周实验排期需要1天头脑风暴且假设质量参差不齐"——LLM辅助假设生成将高质量实验假设产出效率提升4倍，年化加速产品迭代节省规划成本10-20万元

## ② 核心算法逻辑

传统实验假设生成依赖专家直觉，存在确认偏误（Confirmation Bias）和覆盖盲区。LLM 辅助实验假设生成 将大语言模型作为结构化创意引擎，系统性地生成、评分和排序实验候选假设，并结合 ICE 框架（Impact × Confidence × Ease）进行优先级决策。

## ③ 业务应用场景

场景1：新品上线前 Amazon Listing 优化假设生成 - 业务问题：婴儿安全监视器新品上线，团队只有 5 次实验机会（限于流量），需要从 30+ 直觉想法中筛选最高价值的 5 个 - 数据要求：竞品 Listing 分析、历史类似产品实验结果、用户 VOC（Top-10 差评主题） - 预期产出：LLM 生成 20+ 假设，ICE 评分后产出 Top-5 优先实验清单（含效应量预估和实验设计建议） - 业务价值：聚焦高价值实验，相比随机选择假设，实验成功率从 35% 提升到 60%，月均增益约 3 万元
场景2：大促备战期实验路线图自动生成 - 业务问题：618 备战期有 30 天、8 个实验位，需要为 5 条产品线同时规划实验优先级，传统人工排期需要 2 天会议 - 数据要求：各产品线当前转化漏斗数据、历史大促实验结论、人力资源约束 - 预期产出：LLM 生成实验路线图，含依赖关系、并行性建议、风险提示，排期规划从 2 天压缩到 2 小时 - 业务价值：大促实验效率提升 70%，漏斗优化累计额外贡献 GMV 约 10 万元
**三轨验证**： - 成本：调用 DeepSeek API 成本极低（约 $0.01/次生成），工程封装约 1 人天 - 合规：LLM 生成内容不涉及用户数据，无隐私风险；需人工审核后方可执行 - 风险：LLM 生成假设可能不符合 Amazon 平台规则（需加入规则约束 Prompt）

## 输入 / 输出契约

**输入**：竞品 Listing 分析、历史类似产品实验结果、用户 VOC（Top-10 差评主题）；大促路线图场景另需各产品线当前转化漏斗数据、历史大促实验结论与人力资源约束。

**输出**：经 ICE 评分的优先实验清单（卡页示例：生成 20+ 假设、产出 Top-5 清单，含效应量预估与实验设计建议）与含依赖关系、并行性建议、风险提示的实验路线图（示例排期从 2 天压缩到 2 小时）。

## 执行步骤

1. 汇总竞品 Listing、历史实验结果与用户 VOC 素材
2. 用 LLM 生成 20 个以上候选实验假设
3. 用 ICE 框架评分并筛出优先实验清单
4. 补充效应量预估与实验设计建议到优先实验清单
5. 按依赖关系与人力约束生成实验路线图与排期

## 边界与不做

- 何时不用：需要单个实验的样本量与分流设计时用 A/B 实验设计类技能；候选想法不足时先做素材积累。卡页第 7 段无代码模板，落地需另行获取代码。
- 能力边界：只产出假设清单与排期建议，不执行实验；卡页指出 LLM 评分与人工评分相关性约 0.75，最终取舍仍需人工判断。
- 合规边界：生成内容不涉用户数据且须人工审核后才可执行；Prompt 需加入平台规则约束，避免生成不符合 Amazon 规则（如虚假声称）的假设。
