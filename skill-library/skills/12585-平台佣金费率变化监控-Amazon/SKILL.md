## 输入 / 输出契约

**输入**：平台费率页抓取快照与官方 API 费率数据，需保留前后两版可比对版本；以及受影响 SKU 的收入与成本项，粒度到 SKU 与费率项。

**输出**：费率变更清单与受影响 SKU 的 PnL 重算结果，含利润率转负的 SKU，用于及时调整定价或退出策略。

## 执行步骤

1. 按固定频率抓取平台费率页面并保留历史快照
2. 用网页 diff 与官方 API 比对出版本差异
3. 把费率变化代入 SKU 级 PnL 重算利润率
4. 标出利润率转负的 SKU 并给出定价或退出建议

## 边界与不做

- 费率页为图片或强反爬、无法取得可比对文本时不适用，只能等待官方 API 或公告
- 只产出变更监测与重算结果，不自动改价或调整投放
- 抓取须遵守平台条款与爬虫规则，结论需以平台官方公告复核后才可执行
