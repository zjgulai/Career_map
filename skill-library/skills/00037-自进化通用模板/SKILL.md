# Agent 自进化通用模板

> **引用方**: 全部 Agent
> **使用方式**: 各 Agent 自进化部分仅需保留自身特有的触发器和学习要点，通用流程引用本文件。

---

## 通用自进化流程

### 1. 反馈收集（每次任务完成后必做）
- 主动询问：「这份 [输出] 对您有帮助吗？有什么需要调整的？」
- 若商家给出具体反馈，记录到该 Agent 的进化日志

### 2. Memory.md 更新（发现新信息时）
- 商家纠正了某个认知 → 立即更新
- 发现了新的行业术语/缩写 → 追加到行业特征库
- 商家偏好变化（如「下次简版就行」） → 更新偏好记录

### 3. 领域知识积累
- 每次任务中产出的高价值行业知识 → 提交到 shared/ 目录
- 主 Agent 在路由时可引用最新知识

### 4. 模型校准
- 定期复盘输出的准确性（如预测 vs 实际结果）
- 发现系统性偏差时调整分析框架

### 5. 效果追踪
- 记录关键指标：路由准确率、商家满意度、输出被采纳率
- 季度 Review 时汇总改进

## 各 Agent 自进化特有要点速查

> 以下为各 Agent 在通用流程之外的**特有问题**，仅需保留在各自的 Soul.md 中。

| Agent | 特有触发器 | 特有学习要点 |
|-------|-----------|-------------|
| 01-外贸指挥官 | 路由后询问「专家对口吗？」 | 误路由场景→正确路由映射；口语识别表更新；5问建档话术优化 |
| M01-市场情报官 | 报告交付后询问深度/侧重是否符合预期 | 数据错误→正确→来源记录；高/低价值模块标记；ROI模型参数校准 |
| M02-选品设计师 | 选品方向是否遗漏维度或权重不合理 | 品类偏好更新；蓝海指数历史评分追踪；利润公式参数校准 |
| M03-供应链顾问 | 供应商是否符合筛选标准 | 供应商实际表现记录；谈判实际降本幅度校准；1688规则变化追踪 |
| M04-店铺架构师 | 店铺模块效果反馈 | 模块→问题→优化方案记录；星级评定达标时间→关键动作；平台规则变化追踪 |
| O01-广告优化师 | 诊断报告是否清晰、行动项可执行 | 行业特殊水位基准；行业平均CPC/CTR基准积累；新异常模式识别 |
| O02-RFQ狙击手 | 报价方案是否贴合买家需求 | 中标模式记录（话术/时间/类型）；行业话术库积累；分级模型权重校准 |
| O03-经营参谋 | 诊断/日报/复盘/管理方案是否实用 | 商家经营节奏记录；健康基准和异常阈值校准；GAP修复案例库积累 |
| C01-询盘情报师 | 询盘评分和等级判定是否符合商家判断 | 高频问题补充FAQ；行业特有询盘模式更新过滤规则；高效首响话术沉淀 |
| C02-商机管理师 | S类商机卡点诊断是否准确 | 分层阈值校准；新停滞原因解法补充；激活话术回复率数据积累 |
| C03-谈判话术师 | 话术语气是否合适、客户实际反应 | 成功/失败话术案例记录；有效表达方式吸收；月度回复率/成交率统计 |
| C04-成交与客户经理 | PI格式习惯、信保引导效果、客户分层有效性 | PI行业字段补充；信保反驳话术积累；客户留存率验证分层效果 |
| S01-合规顾问 | 合规建议是否有帮助、实际认证有无遗漏 | 新法规/标准更新认证矩阵；实际费用校准估算值；平台规则变更追踪 |
| S02-品牌出海顾问 | 品牌战略分析是否贴合商家实际 | 行业品牌化案例积累；竞品动态更新对标矩阵；市场进入经验完善壁垒库 |

## 进化记录标准格式

```
[日期] [触发事件] [改进内容] [效果验证方式]
```

各 Agent 在记录进化日志时应统一使用以上格式，便于跨 Agent 检索和季度 Review 汇总。

## 协同进化机制

部分 Agent 之间存在知识传递关系，以下为关键协同链路：

- **C01 → C02**：询盘情报师输出已分级商机，商机管理师无缝承接跟进
- **C01 → C03**：高频异议传递给谈判话术师，丰富谈判策略库
- **C04 → O03**：客户留存率数据输出给经营参谋，辅助经营复盘
- **S01 → M04**：合规要求输出给店铺架构师，指导上架合规
- **S01 → O01**：广告合规用词审查
- **M01 → S02**：品类市场数据支撑品牌机会评估
- **O01 → C01**：投放数据优化 CPL 分析精度
