# 行业自适应通用指南

> **引用方**: 全部 Agent
> **使用方式**: 各 Agent 仅需在 Soul 中定义自身行业适配的特殊侧重，通用分类和判断逻辑引用本文件。

---

## 一、行业分类标准

| 行业大类 | 典型品类 | 核心特征 |
|---------|---------|---------|
| 工业品 | 设备、五金、化工、电子元件、机械 | 认证体系优先（CE/UL/ISO）、技术参数敏感、长决策周期、大客户开发路径 |
| 消费品 | 服装、家居、美妆、母婴、宠物、袜子 | 场景化展示优先、视觉营销敏感、MOQ灵活、品牌出海潜力大 |
| 食品/化妆品 | 零食、保健品、护肤品、茶叶 | FDA/HACCP/COSMOS强制认证、保质期敏感、包装标签合规 |
| 建材/装饰 | 瓷砖、灯具、门窗、卫浴 | 工程项目驱动、规格标准化、物流成本敏感 |

---

## 二、自适应触发规则

所有 Agent 在首次交互时：
1. 读取 Memory.md 中的商家画像（行业/品类/商业模式/团队规模/年营收）
2. 根据行业分类标准匹配行业大类
3. 按该行业的核心特征调整工作侧重
4. 若 Memory.md 为空：立即启动首次画像采集流程

---

## 三、通用行业切换

- 商家说「更新我的信息」→ 重新执行画像流程
- 商家切换品类/市场时 → 自动重新匹配行业分类
- 商家跨越多个行业时 → 按当前对话的品类确定侧重

---

## 四、各行业 Agent 工作侧重速查矩阵

> 以下为各行业在不同 Agent 工作场景下的差异化侧重点。各 Agent 仅需关注自身所在行。

### 4.1 工业品

| 工作场景 | 侧重调整 |
|---------|---------|
| 市场调研 | 重点关注技术壁垒、认证门槛、B2B采购决策链、大客户关系型市场特征 |
| 选品分析 | 蓝海指数中「认证壁垒」权重上调至20%，关注技术参数差异化 |
| 供应链 | 重点关注材质认证（ISO/SGS/RoHS）、公差精度、模具开发能力 |
| 店铺搭建 | 首页突出技术参数表+工厂规模+设备清单+检测实验室 |
| 广告投放 | 侧重长尾精准词、行业专业术语关键词；CPC容忍度可适当提高 |
| RFQ报价 | 重点突出技术合规性、定制能力（OEM/ODM参数范围）、售后支持 |
| 经营诊断 | 侧重询盘质量（而非数量）、大客复购率、客单价趋势 |
| 询盘处理 | 重点查认证（FCC/CE/UL）、平台店铺表现、退货率 |
| 商机管理 | 销售周期长（3-12个月），重点看技术方案确认和验厂进展 |
| 谈判话术 | 售后和技术支持是议价点，强调TCO（总拥有成本） |
| 成交管理 | PI须列明技术参数表、安装调试条款、培训服务、备品备件 |
| 合规认证 | 电子产品优先FCC/CE-EMC/UL；机械设备优先CE-MD/UL |
| 品牌出海 | 品牌差异化方向偏技术驱动型 |

### 4.2 消费品

| 工作场景 | 侧重调整 |
|---------|---------|
| 市场调研 | 重点关注消费趋势、社媒热度、季节性波动、DTC与平台混合渠道 |
| 选品分析 | 蓝海指数中「趋势增长」权重上调至35%，关注社媒趋势、视觉差异化 |
| 供应链 | 重点关注定制灵活性（颜色/图案/包装）、打样周期、MOQ弹性 |
| 店铺搭建 | 首页突出生活场景图+品牌故事+设计团队 |
| 广告投放 | 侧重大流量词、竞品词、场景词；关注CTR和主图差异化 |
| RFQ报价 | 重点突出视觉吸引力、包装定制能力、柔性MOQ（支持试单） |
| 经营诊断 | 侧重流量规模、转化率、爆品贡献占比 |
| 询盘处理 | 重点查品牌定位、季节性采购节奏、面料偏好 |
| 商机管理 | 季节性强，交期刚性，重点看打样确认和面料选择进度 |
| 谈判话术 | 面料品质差异和打样速度是议价点，强调快反能力 |
| 成交管理 | PI须明确面料成分、尺码表、色卡编号、包装方式 |
| 合规认证 | 纺织品优先REACH/Oeko-Tex；化妆品优先FDA MoCRA/EU CPNP |
| 品牌出海 | 品牌差异化方向偏设计驱动型/渠道驱动型 |

### 4.3 食品/化妆品

| 工作场景 | 侧重调整 |
|---------|---------|
| 市场调研 | 额外覆盖FDA/EU法规/COSMOS/HALAL等强制认证市场分析 |
| 选品分析 | 强制增加「合规成本」列（FDA注册费/检测报告费/有机认证费） |
| 供应链 | 强制要求供应商具备食品生产许可证/GMP/HACCP |
| 店铺搭建 | 首页强制展示食品安全认证+检测报告+生产车间实拍 |
| 询盘处理 | 重点查FDA/HACCP/有机认证、保质期、成分表 |
| 商机管理 | 电子元器件规格敏感、认证依赖强，重点看规格匹配和认证文件进度 |
| 谈判话术 | 认证价值是议价王牌，强调合规成本差异 |
| 成交管理 | PI须包含保质期条款、成分表、食品安全认证编号 |
| 合规认证 | 食品优先FDA注册/HACCP；化妆品优先FDA MoCRA/EU CPNP/GMP |

### 4.4 建材/装饰

| 工作场景 | 侧重调整 |
|---------|---------|
| 市场调研 | 重点关注工程项目需求、区域建材标准、物流成本分析 |
| 选品分析 | 关注规格标准化程度、物流成本占比、工程项目配套能力 |
| 供应链 | 重点关注产能规模、物流方案优化、工程项目批量交付能力 |
| 店铺搭建 | 首页突出工程项目案例+安装指导+规格参数对照表 |
| 询盘处理 | 重点查工程项目经验、安装能力、本地合规要求 |
| 谈判话术 | 一站式服务和工程项目经验是议价点 |
| 成交管理 | PI须包含安装指导说明、配件明细、质保年限 |

## 五、行业特有的 Memory.md 补充字段

当 Agent 识别到以下行业信息时，应主动补充到 Memory.md：

| 行业 | 建议补充字段 |
|------|-------------|
| 工业品 | 核心技术参数范围、已有认证列表、大客户名单、售后能力说明 |
| 消费品 | 季节性规律、主视觉风格偏好、包装定制需求、社媒渠道布局 |
| 食品/化妆品 | 保质期要求、成分限制清单、已有食品安全认证、冷链需求 |
| 建材/装饰 | 工程项目经验列表、安装能力范围、本地合规特殊要求、物流方案偏好 |

## 六、行业默认行为（Memory.md 为空时）

| Agent 类别 | 默认行为 |
|-----------|---------|
| 外贸指挥官 | 立即启动5问建档流程 |
| 市场情报官 | 默认按消费品类目输出，报告首页提示商家补充画像 |
| 选品设计师 | 默认使用标准蓝海指数权重 |
| 供应链顾问 | 默认按通用消费品标准执行 |
| 店铺架构师 | 默认按消费品通用模板输出，并提示商家补充画像 |
| 广告优化师 | 使用通用关键词筛选逻辑和出价阈值 |
| RFQ狙击手 | 使用通用报价框架 |
| 经营参谋 | 使用通用诊断基准 |
| 询盘情报师 | 主动询问商家主营产品和目标市场 |
| 商机管理师 | 主动询问平均成交周期和客单价范围 |
| 谈判话术师 | 主动询问产品主要卖点和主要竞品 |
| 成交与客户经理 | 主动询问常用贸易条款和PI模板偏好 |
| 合规顾问 | 按产品品类通用认证路径输出，标注「建议确认具体品类」 |
| 品牌出海顾问 | 按OEM/ODM阶段默认输出品牌基础建设方案 |
