# 前车之鉴·ToT 树状推理链

> Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径。适用问题形态：有多个可能解法的开放问题 / 创意生成+筛选 / 策略选择 / 场景规划。

## 何时用

- 问题有多个候选解法，需要系统比较
- 单线推理容易陷入局部最优
- 需要在不确定性下选择最优策略

本技能是**选型图纸 + 相位纪律模板**：用于①给新任务选定执行形态；②设计 subagent / workflow / goal 派工时套用相位结构（checkpoint 做验收门、stop_condition 做终止判据、loop_back 做回环路径）。

## 五链对照（先选对形态）

| 链 | 定位 |
|---|---|
| xmind-chain-react | Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务 |
| xmind-chain-tot | Tree of Thought：从同一节点展开多个推理分支，按评分剪枝，选择最优路径 | **←本链**
| xmind-chain-cot-critic | 深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务 |
| xmind-chain-research | 假设驱动的系统性研究流程：问题→假设→搜集→分析→综合→结论 |
| xmind-chain-per | 目标分解 → 执行序列 → 反思复盘，用于复杂项目/任务规划和执行 |

## 本链 5 相位纪律

| 相位 | 输入 → 输出 | 检查点 | 停止/回环 | 关联模型 |
|---|---|---|---|---|
| 1. 问题解构（Decompose） | 原始问题 → 问题规范：{本质问题, 解法空间维度, 评估标准（可量化）, 约束条件} | 在展开多路径前，先确认：1) 问题的本质是什么？2) 解法空间有哪些维度？3) 评估标准是什么？ | 停止：产出可供下一阶段使用的结果 — | 爱因斯坦式提问_5步重新定义 |
| 2. 分支展开（Branch） | 问题规范 → 分支树：每个分支 = {方向名称, 核心假设, 预期结果, 需要验证的条件} | 在每个维度上展开3-5个候选方向。要求：覆盖常规路径 + 至少1个反常识路径 + 至少1个极端路径 | 停止：覆盖了足够多样的方向（不同策略原理） — | 10个时间黑洞_多巴胺陷阱_ |
| 3. 分支评估（Evaluate） | 所有分支 → 评估矩阵：每个分支有多维评分 + 综合得分 + 优先推进的1-2个分支 | 对每个分支打分。评估维度：可行性（1-5）× 潜在收益（1-5）× 风险（1-5倒序）× 资源消耗（1-5倒序） | 停止：产出可供下一阶段使用的结果 — | 第二层思维_超越共识_决胜决 |
| 4. 深度展开（Deepen） | 排名前2的分支 → 每条路径的完整推演：{步骤序列, 关键决策点, 可能的障碍, 最终状态} | 对排名前2的分支进行深度推理。每个分支推进3-5步，探索「如果选择这条路，接下来会发生什么」 | 停止：产出可供下一阶段使用的结果 →回环至 evaluate | 第二层思维_超越共识_决胜决 |
| 5. 路径选择（Select） | 所有深度推演结果 → 最终决策：{选择的路径, 选择理由, 触发重选的条件, 风险缓解措施} | 综合分支评估和深度推演，选择最优路径。必须说明：1) 为什么选这条而不是其他 2) 哪些条件变化会让这个选择失效 3) 如何降低主要风险 | 停止：产出可供下一阶段使用的结果 — | 10个时间黑洞_多巴胺陷阱_ |

## 落地用法

1. **编排派工**：把上表转成 subagent/workflow 的执行步骤；每相位产出必须先过检查点再进下一相位；触发回环条件时显式回到目标相位，不要静默重试。
2. **运行时纪律**：正在执行的任务陷入停滞时，对照当前相位的 stop_condition 判断是「该停」还是「该回环」，避免无限循环。
3. **关联模型深化**：各相位关联模型的完整推理协议用 xmind-gateway 的查询配方读取（四层结构 system_prompt 可直接注入对应相位执行者）。

## 何时不用 / 转诊

- 纯推理无外部交互 → xmind-chain-cot-critic；要工具交互迭代 → xmind-chain-react
- 多方案并行探索 → xmind-chain-tot；系统性多源研究 → xmind-chain-research
- 多阶段项目管理 → xmind-chain-per；单步低风险任务直接做
