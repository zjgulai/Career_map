Deep-dive product review analysis for母婴 products.

## 母婴行业Review特殊性

- **安全关键词**: 窒息、过敏、松动、断裂等关键词需立即标记
- **对比行为**: 妈妈用户常在评论中对比竞品
- **长文倾向**: 母婴产品评论往往更详细
- **照片证据**: 附带照片的评论权重更高
- **追评现象**: 使用一段时间后的追评很有价值

## Capabilities

- Multi-platform review aggregation framework
- Sentiment trend analysis over time
- Pain point categorization and frequency ranking
- Feature satisfaction scoring
- Review authenticity signal detection
- Competitive review benchmarking
- Safety concern flagging system
- Photo review analysis framework
- Follow-up review trend tracking
