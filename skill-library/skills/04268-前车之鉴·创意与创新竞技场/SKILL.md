# 前车之鉴·创意与创新竞技场

三角色认知对抗协议：三个角色**各自用不同方法独立分析同一问题 → 找出结论间的张力 → 交集=高可信结论，冲突=真实盲区**。这不是头脑风暴，是结构化的对抗验证。

## 什么时候启动

- 头脑风暴开了一场又一场，出来的全是老点子
- 需要一个非共识、但有依据的方向，共识方案都已被人做过了
- 在既有框架里转来转去，怎么都跳不出去
- 所有方案都是「熟悉的安全牌」，缺一个真正不同的选项
- 产品/内容同质化严重，需要打开新的解法空间

用户没明说但符合上述形态时，也应当启动本协议（在回答中直接采用其结构），并告知用户正在使用该思考协议。

## 竞技场协议（完整推理协议，按此结构作答）

你现在运行「创意与创新认知竞技场」模式。三个角色用完全不同的方式生成创意——逆向、平行、重构——通过张力防止「假发散」和「空发散」。

【角色阵容】

角色A — 逆向工程师（逆向思维四型）
立场：正向思路推出来的都是共识答案。把问题反过来，才是新解法富矿。
推理协议：
1. 反转型：把功能、结构或因果颠倒——「怎么让用户多买？」反转为「怎么让用户绝不购买？」
2. 缺点逆用型：当前方案最糟的部分，能不能直接变成卖点？
3. 对立互补型：两个对立选项，能否彼此成就、共生增值，而不是二选一？
核心质疑：如何让这个问题更糟、更停滞？那个答案的反面就是没人走过的路。

角色B — 平行思维主持人（六顶思考帽）
立场：创意卡死＝一顶帽子戴到底。发散和评价必须分轮，混在一起就是互相绞杀。
推理协议：
1. 诊断当前卡在什么帽子（大概率：黑帽过载，每个点子刚冒头就被批判处决）
2. 开绿帽轮：不评价、不解释，量产 10 个方向，越不靠谱越要记录
3. 蓝帽控流程：发散轮结束后才允许批判轮，时间到就切换
核心质疑：你是在评价想法还是生成想法？前者现在没有出场资格。

角色C — 叙事重构师（叙事框架效应）
立场：同一个方案换个故事就是另一个方案。「是什么故事」比「是什么功能」更能打开空间——但故事也能包装平庸。
推理协议：
1. 把当前问题讲成一个故事：主角是谁、冲突是什么、转折在哪
2. 换三种叙事框架各讲一遍（竞争故事 / 成长故事 / 颠覆故事），看哪个框架激活新方案
3. 剥壳检验：剥掉故事外壳，这个方案的功能内核还剩什么？
核心质疑：剩不下东西的创意只是修辞，不是方案。

【竞技场规则】

Phase 1 — 独立生成：三角色各自量产（逆向产出/绿帽产出/重构产出），格式不同，互不评价。

Phase 2 — 寻找张力：
- 逆向工程师的反共识方案 ↔ 叙事师：反共识方向需要付故事成本才能被接受，谁付？
- 主持人：先发散后评价 ↔ 逆向工程师的产出天生会被黑帽当场枪毙，需要绿帽保护期
- 叙事师的重构方案 ↔ 主持人白帽追问：数据支撑在哪？

Phase 3 — 综合：
- 交集（两个以上角色独立到达的方向）= 优先推进
- 冲突（单角色独有）= 标注风险后保留，不否决
- 输出：①「熟悉度 × 可行性」矩阵给全部点子定位 ②三个非共识但可辩护的方向 ③每个方向的剥壳检验结论

【质量门禁】如果产出清单全是安全的老点子，或全是无法落地的狂想——发散和收敛失衡了。分轮重来，两轮都要有产出。

## 停止条件（防拖堂）

当 ①②③ 全部给出，且至少一个方向通过了剥壳检验后停止。

综合输出必须落到决策性产物后即停，不再继续比较/分析本身。

## 三角色速览

- **逆向工程师**（逆向思维四型）—— 立场：正向思路推出来的都是共识答案。把问题反过来——缺点、对立面、反面案例，才是新解法的富矿。
- **平行思维主持人**（六顶思考帽）—— 立场：创意卡死多半因为「一顶帽子戴到底」：全程批判（黑帽过载）或全程发散（绿帽空转）都产不出好创意——必须强制分轮换帽。
- **叙事重构师**（叙事框架效应）—— 立场：同一个方案换个故事就是另一个方案：「这个创意是什么故事」比「这个创意是什么功能」更能打开新空间——但故事也能包装平庸。

## 何时不用 / 转诊

- 要发散产品创意/功能方向 → brainstorm-ideas-existing / brainstorm-ideas-new
- 要攻击现有方案找漏洞 → strategy-red-team
- 要评估已有多个点子的优先级 → weighted-scoring / prioritize-features
- 单点思维模型深化 → xmind-gateway 查库

## 安全边界

创意产出涉及他人成果（文案/设计/竞品对标）时不得抄袭；非共识不等于越界，守住法律与平台规则。
