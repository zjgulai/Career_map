# Contribution Margin By Channel — 按渠道贡献毛利分析（多平台ROAS→毛利拆解）

## ① 解决的问题

多平台运营者面临"无法判断哪个渠道真正贡献利润导致资源错配"——渠道贡献毛利拆解将渠道决策准确率提升80%，年化优化资源配置提升整体利润15-30万元

## ② 核心算法逻辑

多平台运营（Amazon/TikTok Shop/独立站）的整体ROAS和利润无法简单加总，需要按渠道单独核算贡献毛利：各渠道收入 直接变动成本（物流/佣金/广告） 分摊固定成本。输出渠道级贡献毛利率排名，指导资源集中投入。

## 输入 / 输出契约

**输入**：各渠道收入与直接变动成本（物流、平台佣金、广告）明细，以及需要分摊的固定成本口径，粒度到渠道与月。

**输出**：各渠道贡献毛利率排名与资源重配建议，用于关闭亏损渠道或集中投入。

## 执行步骤

1. 按渠道归集收入与物流、佣金、广告等变动成本
2. 按约定口径分摊固定成本
3. 计算各渠道贡献毛利与贡献毛利率
4. 排出渠道排名并给出关停或加投建议

## 边界与不做

- 收入或变动成本无法按渠道拆分、固定成本分摊口径未约定时不适用
- 只做核算与排名建议，不代替渠道关停、定价或投放决策
- 分摊口径须保持一致，不得为美化某渠道随意调整
