# Skill: 查询意图分类与动态路由

## ① 解决的问题

智能搜索面临"用户查询意图混杂导致同一问题触发多套RAG逻辑响应不一"——查询意图分类路由精准识别FAQ/分析/探索三类意图并分流，首答准确率提升46%，无效检索次数降低55%

## ② 核心算法逻辑

Skill: 查询意图分类与动态路由

## ③ 业务应用场景

业务问题：运营每日收到200+混合查询，传统全库检索返回50%无关结果，决策延迟2-4小时。
数据要求： - 广告库：日均投放数据（CPC/CPM/ROAS）、竞品对标 - 供应链库：库存、采购周期 - 法规库：各国广告合规限制 - 用户查询日志（6个月，标注意图）
量化产出： - 检索精准率：52% → 94%（+42%） - 平均响应时间：3.2分钟 → 18秒（↓94%） - 运营决策准确率：68% → 87%（+19pp）

## 输入 / 输出契约

**输入**：多来源知识库（广告库：日均 CPC/CPM/ROAS 与竞品对标；供应链库：库存与采购周期；法规库：各国广告合规限制）以及 6 个月的用户查询日志与意图标注；粒度为 查询。

**输出**：每条查询的意图标签（FAQ / 分析 / 探索）与动态路由目标（命中的知识库与检索策略），以及精准率与响应时间等指标（卡页口径检索精准率 52%→94%、响应 3.2 分钟→18 秒）；供运营查询助手与检索系统使用。

## 执行步骤

1. 整理广告库、供应链库、法规库等分域知识源
2. 用 6 个月查询日志与意图标注训练意图分类器（FAQ / 分析 / 探索）
3. 为每类意图配置对应的检索与回答路径
4. 查询进来先分类再路由，避免全库检索
5. 监控精准率、响应时间与决策准确率并迭代分类边界

## 边界与不做

- 数据不满足：没有意图标注的查询日志时分类器无法训练，路由规则只能手工维护。
- 何时不用：要解决的是电商搜索词的意图与月龄分桶及广告分流，用「搜索层次化意图分类」。
- 能力边界：只做分类与路由，不生成最终答案，也不保证知识库本身的内容质量；卡页的精准率 52%→94%、响应下降 94% 为案例口径。
