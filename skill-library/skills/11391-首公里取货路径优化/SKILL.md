## 输入 / 输出契约

**输入**：取货点级历史业务数据与实时运营数据：供应商或工厂位置、每日取货量（箱数或重量）、车辆载重与容积上限、可用车辆数；粒度到单个取货点与单车次。

**输出**：容量约束下的最优多停靠点取货路线、量化决策支持报告与可操作排线建议，并给出取货运费的优化幅度；供货代与物流调度排车参考使用。

## 执行步骤

1. 汇总多供应商取货的历史业务数据与实时运营数据
2. 按车辆载重与容积约束求解最优多停靠点取货路线
3. 生成量化决策支持报告，列出可操作的取货排线建议
4. 对比优化前后的取货运费，量化降本幅度
5. 记录节省情况，并按业务变化定期重算路线参数
