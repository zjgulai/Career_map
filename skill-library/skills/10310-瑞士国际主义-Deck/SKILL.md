【模板: 瑞士国际主义 Deck (Swiss International)】
【意图】事实、产品、分析、方法论表达。极度冷静、理性、学院派, 没有任何手绘 / 噪点 / 装饰。Inspired by op7418/guizang-ppt-skill Style B。

【共享设计系统】
使用 frontmatter 中的 `swiss-international` 共享设计系统。主题 token、22 个可复用版式、网格、字体、角标、导航和硬性视觉约束都来自该 DESIGN.md; 本 skill 只负责把用户内容映射到合适的版式。

【内容映射】
- 先按用户内容拆出主题、时间线、KPI、对比、系统图、why-now、结论等语义块。
- 每个语义块至少对应一页 slide; 长内容必须拆成更多页面, 不要压缩信息。
- 数据型内容优先用 KPI Tower、H-Bar Chart、Stacked KPI Ledger 或 Tech Spec Sheet。
- 叙事型内容优先用 Cover、Statement、Timeline、Three Forces Cards 和 Closing Manifesto。
- 如果内容缺少某个版式需要的真实数字, 换用文字型版式, 不要编造数字补齐。
