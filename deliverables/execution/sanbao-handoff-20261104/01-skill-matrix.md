# 53 席技能现状与纸库可补范围

**用户已确认**：`paper_to_skills` 著作权归用户，走 A（可直接使用）。

本文件回答：纸库能不能补 53 席的缺口、补多少、哪些是硬配。

---

## 1. 结论

**纸库不是「补缺口」的源，是「加深度」的源。**

| 判断 | 成立性 |
| --- | --- |
| 「纸库补不上 53 席」作为**总量判断** | ✅ 成立 |
| 作为**结构判断** | ✅ 成立，且更精确：纸库本来就已是现有 supply 的上游 |

实测：现有 251 个唯一 supply 里，**143 条是纸库的 p2s 卡**，139 张纸库卡已经入供。未入供的 1,218 张卡里，1,179 张有 staging 正文。

**关键修正**：推演初报 109 个可补，复核发现其中 **8 个在 `classification.json` 里 0 张卡**：

这 8 个是「名字看起来像」被误判为「有技能」——**属于硬配，已剔除**。真实可补是 **101 个**。

## 3. 按平面的结构性问题

| 平面 / 分组 | 可补率 |
| --- | --- |
| 服务 AGT-036~039 | 10/12 = 83.3% |
| 经营 AGT-001~004 | 8/13 = 61.5% |
| **产品 AGT-008~013** | **2/18 = 11.1%** |

**产品工程是纸库最帮不上的地方。** AGT-009 定形、AGT-011 砺器、AGT-012 灵枢三席真补 0。

原因：纸库是研究/算法方法卡，产品定义、结构工程、软件架构这类知识不在其中。

## 7. 版权边界（重要）

用户确认著作权归自己，但**有两个例外**：

| 内容 | 权利 |
| --- | --- |
| 卡片文本（1,357 张 Skill-*.md） | ✅ 用户所有 |
| 卡内引用的 arXiv 摘要、PDF（756 个）、图表 | ❌ 仍属第三方 |
| `papers/` 目录（95 个 md） | ❌ 论文原文，第三方 |

**公开面与出货面必须写清这条边界**，需要 `NOTICE-paper-to-skills.md` 写明 holder + scope + 例外。
