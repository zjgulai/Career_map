# 三宝结果文件分类

`deliverables/` 是项目根目录下的交付层，不替代连续讨论的 canonical 目录。

| 分类 | 内容 | 当前入口 |
| --- | --- | --- |
| `canvas/` | 内部画布、公开地图副本、画布 Playbook | [SANBAO-RESULTS.md](./SANBAO-RESULTS.md) |
| `strategy/` | 三宝完整方案、3+50 数字分身名册 | [三宝完整方案](./strategy/sanbao-canvas-complete-plan.md) |
| `research/` | 来源台账、外部研究和证据边界 | [来源台账](./research/sanbao-sources.md) |
| `execution/` | Tickets、批次执行和验收记录 | [Ticket 批次记录](./execution/sanbao-ticket-batch-2026-10-09.md) |

## 维护规则

1. 继续讨论和画布交互以 `.superpowers/brainstorm/` 与 `.codex/` 下的 canonical 文件为准。
2. 交付副本只用于阅读、交接和发布整理，不单独产生新的业务事实。
3. canonical 文件变化后，重新同步对应分类下的副本，并在 `SANBAO-RESULTS.md` 保持入口一致。
4. `docs/index.html` 是 GitHub Pages 的部署入口，不移动到 `deliverables/`。
5. `skill-library/` 是能力资产库，不并入结果文档分类。
